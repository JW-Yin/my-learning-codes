## 如何察觉集群有节点挂掉？

ZK 临时节点 + 心跳 + Watcher

- 先建持久父节点：如 /cluster/nodes（永久存在，作为挂载点）
- 服务节点连 ZK：作为客户端与 ZK 建立 TCP 长连接（Session 会话）
- 创建临时节点：服务节点在父节点下创建临时节点，临时节点绑定当前会话
- 心跳保活：服务节点主动向 ZK 发心跳，维持会话不超时
- 宕机触发删除：节点宕机 / 断网→无法发心跳→会话超时→ZK 自动删除临时节点
- 通知管理者：通过 Watcher 主动推送节点变化通知
---
## Watcher 是什么？

Watcher = ZK 的主动报警器 / 订阅通知，监听父节点 /cluster/nodes 的子节点变化，节点上下线时，ZK 主动推通知，无需轮询。

- 一次性触发：触发一次就失效，想继续监听需重新注册
- 只通知变化：不发具体数据，通知后客户端自己拉取最新数据
- 精准监听：可监听节点创建 / 删除 / 数据改 / 子节点变
