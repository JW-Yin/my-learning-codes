#### 8.3 指针基础
- 什么是指针：内存地址
- 地址运算符 `&` 和解引用运算符 `*`

- 指针的作用：避免大对象拷贝、修改函数外变量

#### 8.4 结构体方法

#### 8.5 `new` 与 `make` 的彻底辨析
- **为什么要有两个？**：slice/map/chan 底层结构复杂，必须初始化内部指针
- `new(T)`：分配零值内存，返回 `*T`
- `make(T, ...)`：仅用于 slice、map、chan，返回已初始化的 `T`

- 交叉编译为 Windows/macOS/Linux 可执行文件

### 第14章 Go 语言生态地图与进阶指南
*（本章不涉及代码练习，为读者描绘后续学习路线）*

#### 14.1 标准库 vs 第三方库的选择原则
- 能用标准库解决的问题尽量不引入外部依赖
- 当标准库在性能、易用性上有明显不足时选用成熟三方库

#### 14.2 Web 框架生态
- **Gin**：高性能、中间件丰富，推荐初学者首选
- **Echo**：轻量、路由性能优秀
- **Fiber**：受 Express 启发，极高性能

#### 14.3 数据库操作库
- **database/sql** 标准库基础（以 SQLite 为例简述，不展开代码）
- **GORM**：功能全面的 ORM，适合快速开发
- **Ent**：类型安全的图数据 ORM，更现代
- **sqlx**：轻量封装，适合手写 SQL 场景

#### 14.4 命令行工具开发
- **Cobra**：强大的 CLI 框架（Kubernetes、Hugo 等使用）
- **Viper**：配置管理解决方案（支持多种格式和环境变量）

#### 14.5 微服务与云原生
- **gRPC** 与 Protocol Buffers：高性能跨语言 RPC
- **Go-Zero**、**Kratos**：国内主流微服务框架
- **Kubernetes** 二次开发：Client-go、Operator 模式

#### 14.6 认识泛型：从看懂函数签名开始
- Go 1.18+ 泛型基础语法：`func F[T any](v T) T`
- 标准库泛型示例：`slices.SortFunc`、`maps.Keys`
- **定位**：不要求写泛型代码，但要能读懂

#### 14.7 持续学习的 5 条建议
1. 阅读标准库源码（从 `net/http` 开始）
2. 为开源项目提交 Issue 或 PR
3. 用 Go 重写自己以前用其他语言实现的小工具
4. 关注 Go 官方博客和 Release Notes
5. 参与 Go 社区（如 Gopher China、Go 夜读）
