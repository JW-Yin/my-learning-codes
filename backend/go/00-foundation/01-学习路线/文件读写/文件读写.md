# Go 标准库：文件常规操作 完整教程
## 核心依赖包
Go 操作文件只用 **3 个标准库**，无需第三方包：
- `os`：系统级文件操作（打开、创建、关闭）
- `bufio`：**带缓冲的高效读写**（逐行读取、批量写入首选）
- `io`：基础 IO 接口（辅助读写）

---

## 一、核心前置知识
文件操作固定**三步流程**（必须遵守）：
1. 打开/创建文件
2. 执行读/写操作
3. 关闭文件（防止资源泄漏）

---

## 二、逐知识点精讲
### 1. 打开文件：`os.OpenFile`
`os.OpenFile` 是 **Go 最通用的文件打开函数**
（`os.Open()` 只是它的「只读简化版」）

#### 函数定义
```go
func OpenFile(文件路径 string, 打开模式 int, 权限 FileMode) (*文件对象, error)
```

#### 关键参数
1. **打开模式（必选，可组合使用）**
   ```go
   os.O_RDONLY   // 只读
   os.O_WRONLY   // 只写
   os.O_RDWR     // 读写
   os.O_CREATE   // 文件不存在则创建
   os.O_APPEND   // 写入时追加（不清空原有内容）
   os.O_TRUNC    // 打开时清空文件
   ```
2. **文件权限**：固定写 `0644` 即可（Unix 生效，Windows 忽略）

#### 最常用组合
```go
// 1. 只读打开（读取文件用）
os.OpenFile("test.txt", os.O_RDONLY, 0644)

// 2. 只写+创建+清空原有内容（覆盖写入）
os.OpenFile("test.txt", os.O_WRONLY|os.O_CREATE|os.O_TRUNC, 0644)

// 3. 只写+创建+追加内容（不覆盖，日志常用）
os.OpenFile("test.txt", os.O_WRONLY|os.O_CREATE|os.O_APPEND, 0644)
```

---

### 2. 关闭文件：`defer file.Close()`
**固定写法：打开文件无错误后，立刻 defer 关闭**
- `defer`：函数退出时**自动执行关闭**
- 绝对不能省略，否则会造成文件句柄泄漏

```go
file, err := os.OpenFile(...)
if err != nil {
    // 打开失败，处理错误
    log.Fatal(err)
}
// ✅ 正确：打开成功后，立即 defer 关闭
defer file.Close()
```

---

### 3. 写入文件：`file.Write`
两种写入方式：
1. **直接写入**（小文件）
2. **缓冲写入**（大文件/频繁写入，效率更高）

#### 示例：覆盖写入文件
```go
package main

import "log"
import "os"

func main() {
	// 打开文件：只写+创建+清空
	file, err := os.OpenFile("demo.txt", os.O_WRONLY|os.O_CREATE|os.O_TRUNC, 0644)
	if err != nil {
		log.Fatal("打开文件失败：", err)
	}
	defer file.Close()

	// 写入：Write 接收字节切片
	content := []byte("Hello Go 文件操作！\n")
	_, err = file.Write(content)
	if err != nil {
		log.Fatal("写入失败：", err)
	}

	// 简化写入字符串
	_, err = file.WriteString("第二行内容\n")
}
```

### 4. 逐行读取：`bufio.NewScanner`
**Go 官方推荐的逐行读取方式**，简单易用
配合文件对象，自动按行分割内容

#### 示例：逐行读取文件
```go
package main

import (
	"bufio"
	"log"
	"os"
)

func main() {
	// 只读打开文件
	file, err := os.OpenFile("demo.txt", os.O_RDONLY, 0644)
	if err != nil {
		log.Fatal(err)
	}
	defer file.Close()

	// 创建扫描器
	scanner := bufio.NewScanner(file)

	// 逐行读取
	for scanner.Scan() {
		// 获取当前行内容
		line := scanner.Text()
		log.Println("读取到行：", line)
	}

	// 检查读取过程中是否出错
	if err := scanner.Err(); err != nil {
		log.Fatal("读取失败：", err)
	}
}
```

---

### 5. ⚠️ 核心警告：`Scanner` 默认缓冲区 64KB
这是**高频坑点**，必须记住：
`bufio.Scanner` **默认缓冲区大小 = 64KB**
如果文件中**某一行的长度超过 64KB**，读取会直接报错！

#### 解决方案：自定义超大缓冲区
```go
// 给 Scanner 设置 1MB 缓冲区（解决超长行问题）
const maxScanTokenSize = 1024 * 1024 // 1MB
buf := make([]byte, maxScanTokenSize)
scanner.Buffer(buf, maxScanTokenSize)
```

#### 完整兼容超长行的读取代码
```go
package main

import (
	"bufio"
	"log"
	"os"
)

func main() {
	file, err := os.Open("demo.txt")
	if err != nil {
		log.Fatal(err)
	}
	defer file.Close()

	scanner := bufio.NewScanner(file)

	// ✅ 关键：设置 1MB 缓冲区，支持超长行
	const maxSize = 1024 * 1024
	scanner.Buffer(make([]byte, maxSize), maxSize)

	// 逐行读取
	for scanner.Scan() {
		log.Println(scanner.Text())
	}

	if err := scanner.Err(); err != nil {
		log.Fatal("读取错误：", err)
	}
}
```

## 三、完整综合示例（读 + 写 + 逐行处理）
```go
package main

import (
	"bufio"
	"log"
	"os"
)

func main() {
	// ========== 1. 写入文件 ==========
	file, err := os.OpenFile("test.txt", os.O_WRONLY|os.O_CREATE|os.O_TRUNC, 0644)
	if err != nil {
		log.Fatal(err)
	}
	_, err = file.WriteString("第一行\n第二行\n第三行\n")
	file.Close() // 关闭写入的文件

	// ========== 2. 逐行读取文件 ==========
	file, err = os.OpenFile("test.txt", os.O_RDONLY, 0644)
	if err != nil {
		log.Fatal(err)
	}
	defer file.Close()

	scanner := bufio.NewScanner(file)
	// 支持超长行
	scanner.Buffer(make([]byte, 1024*1024), 1024*1024)

	// 遍历读取
	for scanner.Scan() {
		log.Println("内容：", scanner.Text())
	}

	// 检查错误
	if err = scanner.Err(); err != nil {
		log.Fatal(err)
	}
}
```
