
### 🧱 第一阶段：基础操作与核心类型

**目标**：能安全地打开、创建、读写和关闭文件，理解 `os.File` 的基本方法。

| 知识点 | 核心内容 | 常用函数/类型 |
| :--- | :--- | :--- |
| 打开与创建文件 | 文件打开模式（只读、只写、追加、创建）与权限位 | `os.Open`、`os.Create`、`os.OpenFile`、`os.O_*` 常量 |
| 基础读写 | 字节切片读写、直接写入字符串 | `file.Read`、`file.Write`、`file.WriteString` |
| 资源释放 | 理解 `defer` 的必要性，避免资源泄露 | `defer file.Close()` |
| 文件信息与状态 | 判断文件是否存在、获取大小、修改时间 | `os.Stat`、`os.IsNotExist`、`file.Stat` |

**实践任务**：
- 实现一个程序，将用户输入的字符串追加写入 `log.txt`。
- 读取一个文本文件，并将内容全部打印到控制台。

### 🧰 第二阶段：常用辅助包与高效读写

**目标**：掌握 `io` / `bufio` / `fmt` 包提供的便捷读写工具，处理常见场景。

| 知识点 | 核心内容 | 常用函数/类型 |
| :--- | :--- | :--- |
| 便捷工具函数 | 快速读取整个文件、快速写入整个文件 | `os.ReadFile`、`os.WriteFile`（Go 1.16+ 替代 `ioutil`） |
| 带缓冲的读写 | 减少系统调用，提升大文件或高频操作性能 | `bufio.NewReader`、`bufio.NewWriter`、`bufio.NewScanner` |
| 按行读取 | 处理日志、配置文件等文本数据的最佳实践 | `scanner.Scan()`、`scanner.Text()` |
| 格式化写入 | 像写控制台一样写文件 | `fmt.Fprintf`、`fmt.Fprintln` |
| 文件指针操作 | 跳转读写位置、获取当前位置 | `file.Seek`、`file.SeekStart` / `SeekCurrent` / `SeekEnd` |

**实践任务**：
- 使用 `bufio.Scanner` 读取一个 CSV 文件，统计总行数。
- 使用 `bufio.Writer` 缓冲写入 100 万行随机数字到文件，对比有无缓冲的耗时差异。

### 📁 第三阶段：目录操作与文件系统交互

**目标**：熟练进行文件系统的目录遍历、重命名、删除等管理操作。

| 知识点 | 核心内容 | 常用函数/类型 |
| :--- | :--- | :--- |
| 目录遍历 | 递归读取目录下所有文件、过滤特定后缀 | `os.ReadDir`（Go 1.16+）、`filepath.WalkDir` |
| 路径操作 | 安全地拼接、拆分、清理路径，适配不同操作系统 | `path/filepath.Join`、`filepath.Base`、`filepath.Ext` |
| 文件管理 | 重命名、移动、删除、创建临时文件/目录 | `os.Rename`、`os.Remove` / `RemoveAll`、`os.MkdirAll`、`os.CreateTemp` |
| 文件拷贝 | 实现文件复制功能（没有标准库直接支持，需手动实现） | 结合 `io.Copy` 和文件句柄 |

**实践任务**：
- 编写一个工具，查找当前目录及子目录下所有 `.go` 文件并打印路径。
- 实现一个安全的文件拷贝函数，处理目标文件已存在的情况。

### 🚀 第四阶段：高级话题与生产级实践

**目标**：处理特殊文件格式、并发安全、内存映射等高性能场景。

| 知识点 | 核心内容 | 常用函数/类型 / 包 |
| :--- | :--- | :--- |
| 编码与解码 | 处理 JSON、XML、Gob、CSV 等格式化数据文件 | `encoding/json`、`encoding/csv`、`encoding/gob` |
| 二进制文件 | 按大小端、特定结构体读取和写入二进制数据 | `encoding/binary` |
| 并发文件写入 | 多 Goroutine 写同一文件的竞态问题与解决方案 | `sync.Mutex`、通道 + 单写入协程模式 |
| 文件锁 | 防止多个进程同时写入导致的冲突 | `syscall.Flock` (Unix)、`golang.org/x/sys/windows` (Windows) |
| 内存映射 I/O | 极高效的大文件读写方式，减少内存拷贝 | `syscall.Mmap`、`golang.org/x/exp/mmap` |
| 原子文件操作 | 保证文件写入的完整性（先写临时文件再重命名） | 结合 `os.CreateTemp` 和 `os.Rename` |
| 流式处理 | 处理超大文件或网络数据流，内存占用极低 | `io.Copy`、`io.TeeReader`、`io.Pipe` |

**实践任务**：
- 实现一个简单的日志轮转库：当日志文件超过 10MB 时自动归档并创建新文件。
- 使用 `encoding/csv` 解析一个百万行销售记录 CSV，计算总销售额（流式处理，不一次性读入内存）。
- 尝试用内存映射方式读取一个大型二进制文件，提取其中某段数据。
