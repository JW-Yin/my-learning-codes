# 跑通第一个GO项目

## 安装 Go 语言开发包(SDK)

- 执行：`sudo dnf install golang`，以安装Go编译器、Go标准库、Go命令行工具
- 重开新命令行，验证安装：`go version`

## 配置 GOPROXY 代理

- `go env -w GOPROXY=https://goproxy.cn,direct`
- 验证代理：`go env GOPROXY`

## 检查环境
- 执行：`go env GOROOT GOPATH GOPROXY`
- GOROOT 是 Go SDK 的安装目录，存放标准库、编译器、工具链
- GOPATH 是 Go 的工作目录，用于存放第三方依赖缓存、编译后的二进制文件
- GOPROXY 是 Go 模块的代理地址，解决国内依赖下载超时 / 失败问题

## 输出"hello world"并拉取"uuid"依赖，验证环境已没问题

新建`hello.go`文件，写入以下内容：
```go
    package main
    import (
        "fmt"
        "github.com/google/uuid"
    )
    func main() {
        fmt.Println("Hello UUID:", uuid.NewString())
    }
```
终端执行：`go mod init demo && go mod tidy && go run hello.go`，能正常打印输出，说明SDK安装完全正常。

- go mod init demo → 生成 go.mod，当前目录正式成为 Go 项目模块
- 模块 (Module)：一个包含go.mod文件的目录，是 Go 项目的基本单元，go.mod定义了模块名、Go 版本、依赖包及版本。
- 包 (Package)：同一个目录下的.go文件组成一个包，一个模块可包含多个包。
- go mod tidy → 扫描代码，发现缺 uuid，自动下载，更新 go.mod，生成 go.sum
- 每次修改了代码里的 import 语句，就执行一次 go mod tidy

## 彻底移除Go环境
```bash
# 卸载 Go SDK 主包
sudo dnf remove golang

# 清理因安装 Go 而自动安装、但现在不再需要的依赖包（可选但推荐）
sudo dnf autoremove

# 删除 Go 的用户配置目录（包含 env 配置文件）
rm -rf ~/.config/go

# 删除Go的GOPATH工作目录，清理所有依赖缓存、编译后的二进制文件
rm -rf ~/go

# 检查并清理 Shell 配置文件，如有export GOROOT/GOPATH/GOPROXY的行，删除后保存退出
vim ~/.bashrc
source ~/.bashrc
```
