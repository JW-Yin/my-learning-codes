
## 一、核心定位（一句话记死）

| 工具       | 核心角色                |解决的核心问题                          |
|------------|-------------------------|-----------------------------------------|
| **FastAPI** | Python Web API 框架（规则层） | 快速写接口、自动参数校验、自动生成文档  |
| **Uvicorn** | ASGI 服务器（运行层）|持久监听端口、接收/转发请求、运行 FastAPI |

---

## 二、为什么需要两者协作？（缺一不可）
### 1. 没有 FastAPI 不行
- 你没法便捷地定义接口规则（比如 `/api/add` 该怎么处理请求）；
- 你要手动写代码解析前端 JSON、校验参数、生成文档，效率极低。

### 2. 没有 Uvicorn 不行
- FastAPI 只是“纸上的代码”，不能监听端口、接收网络请求；
- 你写好的 FastAPI 接口，必须靠 Uvicorn 才能对外提供 Web 服务。

### 3. 协作流程（一次请求的完整链路）
```
前端发请求 → Uvicorn（监听8000端口，接住请求）→ FastAPI（校验参数、处理业务）→ Uvicorn（把结果返回给前端）
```

---

## 三、核心特性速查（复盘时快速回忆）
### FastAPI 核心特性（3个最关键）
1. **自动参数校验**：用 Pydantic 模型，不用手动写代码检查“前端传的是不是字符串”；
2. **自动 API 文档**：零配置生成 `/docs`（Swagger，可直接测试）和 `/redoc`（简洁文档）；
3. **原生异步支持**：遵循 ASGI 协议，处理高并发请求（比如多用户同时查 RAG）比同步 Flask 快 10 倍以上。

### Uvicorn 核心特性（2个最关键）
1. **ASGI 服务器**：专门适配 FastAPI/Starlette 等异步框架，性能高；
2. **开发友好**：支持 `--reload` 热重载（改代码自动重启，不用手动停服务）。

## 四、实战速查（复盘时直接照做）
### 1. 安装依赖
```bash
# 开发环境（一步到位）
pip install fastapi uvicorn[standard]
```

### 2. 最小 FastAPI 代码（`main.py`）
```python
from fastapi import FastAPI
from pydantic import BaseModel

# 1. 创建应用实例
app = FastAPI(title="我的 FastAPI 复盘")

# 2. 定义请求模型（POST 用）
class AddRequest(BaseModel):
    content: str
    age: int = 18

# 3. 定义接口
@app.get("/")
def root():
    return {"message": "欢迎！文档在 /docs"}

@app.post("/add")
def add_data(request: AddRequest):
    return {"success": True, "content": request.content, "age": request.age}
```

### 3. 启动服务（开发环境）
```bash
# 核心命令（复盘时直接用）
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```
- `main:app`：`main.py` 里的 `app = FastAPI()` 实例；
- `--reload`：开发模式热重载（生产环境不要用）；
- `--host 0.0.0.0`：允许局域网其他机器访问；
- `--port 8000`：指定端口（被占用就改 8001）。

### 4. 测试接口
打开浏览器访问 `http://localhost:8000/docs`，直接在网页上测试接口（替代 Postman）。

## 五、生产环境部署速查（日后上线用）
### 核心选型：Gunicorn + Uvicorn Workers
- 为什么？Uvicorn 单进程扛不住高并发，Gunicorn 做进程管理器，管理多个 Uvicorn Worker。

### 实战命令
```bash
# 1. 安装生产依赖
pip install fastapi uvicorn[standard] gunicorn

# 2. 启动生产服务（4个Worker，CPU核心数*2+1）
gunicorn main:app \
  --workers 4 \
  --worker-class uvicorn.workers.UvicornWorker \
  --bind 0.0.0.0:8000 \
  --timeout 120 \
  --access-logfile - \
  --error-logfile -
```

## 六、关键细节速查（避坑用）
### 1. 跨域问题（前端对接必处理）
在 `main.py` 开头加：
```python
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],  # 开发环境允许所有，生产环境指定具体域名（比如"http://localhost:5173"）
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

### 2. 前后端对接（不管用什么前端）
- FastAPI 只负责「提供 JSON 接口」；
- 前端只需要「发 HTTP 请求（GET/POST）、解析 JSON」；
- 原生 HTML+AJAX、Vue、React 都能对接，完全解耦。

---

## 七、一句话总结（复盘时的核心锚点）
> **FastAPI 是“规则制定者”**：写接口、校验参数、生成文档；  
> **Uvicorn 是“运行载体”**：监听端口、接收请求、运行 FastAPI；  
> 两者协作，才能对外提供完整的 Web 服务。
