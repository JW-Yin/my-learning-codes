
## 一、psql 核心定位（快速回顾）
psql 是 **PostgreSQL interactive terminal**（PostgreSQL 交互式终端）的缩写，是 PostgreSQL 官方原生的命令行客户端，用于连接数据库、执行 SQL、管理元数据，是 DBA 和开发者日常操作 PostgreSQL 的核心工具。


## 二、安装与连接数据库（重点）
### 1. 安装与验证
psql 通常随 PostgreSQL 一起安装，无需单独下载：
- Ubuntu/Debian：`sudo apt install postgresql-client`（仅装客户端）
- Fedora：`sudo dnf install postgresql`
- 验证安装：`psql --version`

### 2. 连接参数详解（每个参数标英文缩写）
| 参数 | 英文全称 | 作用 | 默认值 |
|------|----------|------|--------|
| `-h` | **h**ost | 数据库服务器地址 | `localhost` |
| `-p` | **p**ort | 数据库端口 | `5432` |
| `-U` | **U**ser | 登录用户名（注意大写） | 当前系统用户名 |
| `-d` | **d**atabase | 要连接的数据库名 | 与用户名同名 |
| `-W` | **W**password | 强制提示输入密码（即使配置了免密） | 无 |

### 3. 常见连接场景示例
```bash
# 场景1：本地默认连接（用户 postgres，库 postgres）
psql -U postgres -d postgres

# 场景2：连接远程服务器
psql -h 192.168.1.100 -p 5432 -U myuser -d mydb

# 场景3：简化连接（如果库名=用户名，可省略 -d）
psql -U myuser -h localhost
```

### 4. 免密连接配置（.pgpass）
为避免每次输入密码，可在用户主目录下创建 `.pgpass` 文件：
```bash
# 1. 创建文件（Linux/Mac）
touch ~/.pgpass
chmod 600 ~/.pgpass  # 必须设置权限为600，否则不生效

# 2. 写入内容（格式：主机:端口:库名:用户名:密码）
echo "localhost:5432:my_vector_db:postgres:123456" >> ~/.pgpass
```
配置后，连接对应库时无需输入密码。


## 三、常用元命令分类详解（重点，标英文全称）
元命令是 psql 特有的“快捷键”，以 `\` 开头，无需分号结尾，用于快速操作数据库元数据。

### 1. 帮助与退出
| 命令 | 英文全称 | 作用 |
|------|----------|------|
| `\?` | **?**（help） | 查看所有元命令的帮助 |
| `\h <SQL关键字>` | **h**elp（SQL help） | 查看 SQL 语法帮助（如 `\h select`） |
| `\q` | **q**uit | 退出 psql |

### 2. 数据库级操作
| 命令 | 英文全称 | 作用 | 示例 |
|------|----------|------|------|
| `\l` | **l**ist | 列出所有数据库 | `\l` |
| `\l+` | **l**ist **e**xtended | 列出所有数据库（含大小、权限等详情） | `\l+` |
| `\c <库名>` | **c**onnect | 切换到指定数据库 | `\c my_vector_db` |
| `\c <库名> <用户名>` | **c**onnect | 切换库并切换用户 | `\c mydb myuser` |

### 3. 表与元数据查看
| 命令 | 英文全称 | 作用 | 示例 |
|------|----------|------|------|
| `\dt` | **d**escribe **t**ables | 列出当前库的所有表 | `\dt` |
| `\dt+` | **d**escribe **t**ables **e**xtended | 列出所有表（含大小、描述等详情） | `\dt+` |
| `\d <表名>` | **d**escribe | 查看指定表的结构（字段、类型、索引、外键） | `\d langchain_pg_embedding` |
| `\d+ <表名>` | **d**escribe **e**xtended | 查看表结构（含存储参数、字段描述） | `\d+ users` |
| `\du` | **d**escribe **u**sers | 列出所有用户和权限 | `\du` |
| `\dv` | **d**escribe **v**iews | 列出所有视图 | `\dv` |
| `\di` | **d**escribe **i**ndexes | 列出所有索引 | `\di` |

### 4. 数据导入导出
| 命令 | 英文全称 | 作用 | 示例 |
|------|----------|------|------|
| `\i <文件路径>` | **i**nclude | 执行外部 SQL 脚本文件 | `\i /home/user/init.sql` |
| `\o <文件路径>` | **o**utput | 将接下来的查询结果输出到指定文件 | `\o /home/user/result.txt` |
| `\o` | **o**utput（关闭） | 停止输出到文件，恢复到屏幕显示 | `\o` |
| `\copy <表名> from '<文件路径>'` | **copy** | 从本地文件导入数据到表（需文件格式匹配） | `\copy users from '/home/user/users.csv' csv header` |
| `\copy <表名> to '<文件路径>'` | **copy** | 将表数据导出到本地文件 | `\copy users to '/home/user/users.csv' csv header` |

### 5. 显示设置调整
| 命令 | 英文全称 | 作用 | 示例 |
|------|----------|------|------|
| `\x on/off` | e**x**panded | 开启/关闭扩展显示模式（适合查看宽表/长向量） | `\x on` |
| `\t on/off` | **t**uples only | 开启/关闭仅显示数据行（隐藏列名、行数提示） | `\t off` |
| `\pset border <0/1/2>` | **pset** border | 设置表格边框样式（0=无边框，1=内边框，2=全边框） | `\pset border 2` |
| `\pset all default` | **pset** all default | 一键重置所有显示设置为默认 | `\pset all default` |


## 四、SQL 执行实用技巧
1. **分号结尾**：所有 SQL 语句必须以 `;` 结尾才会执行，否则提示符会变成 `-#`（表示语句未结束），此时按 `Ctrl+C` 可取消未完成的输入。
2. **\g 执行**：如果忘记加分号，可输入 `\g` 代替分号执行上一条语句。
3. **\e 编辑**：输入 `\e` 会打开系统默认编辑器（如 vim），编辑上一条 SQL 语句，保存退出后自动执行。
4. **历史命令**：
   - 按上下方向键查看之前执行过的命令；
   - 输入 `\s` 查看所有历史命令；
   - 输入 `\s <文件路径>` 将历史命令保存到文件。
5. **自动补全**：按 `Tab` 键可自动补全数据库名、表名、字段名、SQL 关键字。


## 五、个性化配置（.psqlrc）
可在用户主目录下创建 `.psqlrc` 文件，设置 psql 的默认行为，每次启动 psql 时自动加载：
```bash
# 1. 创建文件
touch ~/.psqlrc

# 2. 写入配置（示例）
echo "\pset border 2" >> ~/.psqlrc  # 默认全边框
echo "\x off" >> ~/.psqlrc          # 默认关闭扩展模式
echo "\timing on" >> ~/.psqlrc      # 默认显示 SQL 执行时间
echo "set search_path to public;" >> ~/.psqlrc  # 默认搜索路径
```


## 六、常见问题快速排查
| 问题现象 | 原因 | 解决方法 |
|----------|------|----------|
| 提示符变成 `-#` | SQL 语句未加分号 | 按 `Ctrl+C` 取消，或补充分号 `;` |
| 连接失败：`Connection refused` | 服务器未启动、端口错误、防火墙拦截 | 检查 PostgreSQL 状态：`sudo systemctl status postgresql`；检查端口：`netstat -tuln | grep 5432` |
| 连接失败：`Peer authentication failed` | 本地连接时用户名与系统用户名不匹配 | 使用 `-U` 指定正确用户名，或配置 `pg_hba.conf` |
| 查询无输出但 `count(*)` 有值 | 显示模式问题（如 `\t on` 或向量太长） | 用 `\pset all default` 重置显示设置，或用 `\x on` 查看长内容 |


## 七、复盘速查表（核心命令快速查）
```bash
# 连接数据库
psql -U postgres -d mydb -h localhost -p 5432

# 常用元命令
\l          # 列数据库
\c mydb     # 切库
\dt         # 列表
\d users    # 看表结构
\du         # 列用户
\i init.sql # 执行脚本
\q          # 退出

# 显示设置
\x on/off   # 扩展模式
\t on/off   # 仅数据行
\pset all default # 重置显示
```
