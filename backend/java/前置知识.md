
### 一、核心总览（先记最关键的包含关系）
```
JDK（Java开发工具包） ⊃ JRE（Java运行环境） ⊃ JVM（Java虚拟机）
```
- 「⊃」表示“包含”，JDK 是“最大的包”，JVM 是“最核心的执行引擎”；
- 所有 Java 程序的运行，底层都是 **JVM 执行字节码**，JRE/JDK 只是给 JVM 提供运行支撑。

### 二、JDK vs JRE 核心维度对比（复盘核心）
| 维度             | JRE（Java Runtime Environment）       | JDK（Java Development Kit）                              |
| -------------- | ----------------------------------- | ------------------------------------------------------ |
| **核心定义**       | Java 程序的「最小运行环境」                    | Java 程序的「完整开发环境」                                       |
| **核心组成**       | JVM + Java 核心类库（String/ArrayList 等） | JRE + 开发工具（编译器、调试器、文档工具等）                              |
| **核心能力**       | 仅能「运行」已编译的 .class/.jar 字节码文件        | 既能「开发/编译」.java 源文件，也能「运行」字节码文件                         |
| **关键工具**       | 只有 `java`（运行字节码）                    | 新增 `javac`（编译 .java→.class）、`javadoc`（生成文档）、`jdb`（调试）等 |
| **适用人群**       | 仅运行 Java 程序的用户（如云服务器部署）             | 开发 Java 程序的开发者（如你做电商毕设）                                |
| **Ubuntu 安装包** | `openjdk-xx-jre`（如 openjdk-21-jre）  | `openjdk-xx-jdk`（如 openjdk-21-jdk）                     |
| **识别标志**       | 目录下只有 `java` 命令，无 `javac`           | 目录下同时有 `java` + `javac` 命令（核心！）                        |

### 三、JDK 和 JRE 的核心联系（复盘必记）
1. **依赖关系**：JDK 必须依赖 JRE（开发完的程序要运行，底层还是 JRE 里的 JVM）；JRE/JDK 都不能脱离 JVM 单独运行（JVM 是执行核心）。
2. **运行逻辑一致**：无论用 JRE 还是 JDK 运行程序，最终都是调用 JVM 执行字节码，效果完全一样。
3. **安装关联**：
   - Ubuntu 中装 JDK 会自动安装对应的 JRE（无需单独装）；
   - 装 JRE 仅得到运行能力，补装 JDK 包（如 `openjdk-21-jdk`）会在原有 JRE 基础上新增开发工具，不覆盖原有文件。
4. **版本匹配**：运行程序的 JRE/JDK 版本 ≥ 编译程序的 JDK 版本（比如你用 JDK21 编译的电商项目，可在 JRE21/JRE17 上运行，反之则报错）。
