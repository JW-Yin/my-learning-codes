# Fedora 快速复刻 P4-Tutorials 虚拟机 完整极简手册
适配：Fedora 39+/43 通用，**换另一台 Fedora 直接照做，零踩坑**
核心原则：
**禁止手动新建虚拟机+挂载VMDK**（必炸引导/键盘失效）
全程只用：KVM基础环境 + `virt-v2v` 官方OVA一键转换

## 一、前置：Fedora 先装好 KVM 全套（必做）
复制整段一键执行，执行完**重启电脑**
```bash
# 1. 安装虚拟化组件 + 授权
sudo dnf install @virtualization -y
sudo systemctl enable --now libvirtd
sudo usermod -aG libvirt $USER

# 2. 初始化 default NAT 网络
sudo virsh net-define --file <(cat <<EOF
<network>
  <name>default</name>
  <forward mode='nat'/>
  <bridge name='virbr0' stp='on' delay='0'/>
  <ip address='192.168.122.1' netmask='255.255.255.0'>
    <dhcp>
      <range start='192.168.122.2' end='192.168.122.254'/>
    </dhcp>
  </ip>
</network>
EOF
)
sudo virsh net-start default
sudo virsh net-autostart default

# 3. 永久网络修复（WiFi/有线不掉网）
sudo systemctl stop iptables
sudo systemctl disable iptables
sudo dnf remove iptables-services -y
echo "net.ipv4.ip_forward=1" | sudo tee /etc/sysctl.d/99-kvm-forward.conf
sudo sysctl -p /etc/sysctl.d/99-kvm-forward.conf
NIC=$(ip route get 1.1.1.1 | awk '{print $5}')
sudo firewall-cmd --permanent --zone=trusted --add-interface=virbr0
sudo firewall-cmd --permanent --add-masquerade
sudo firewall-cmd --permanent --direct --add-rule ipv4 filter FORWARD 0 -i virbr0 -o $NIC -j ACCEPT
sudo firewall-cmd --permanent --direct --add-rule ipv4 filter FORWARD 0 -i $NIC -o virbr0 -m state --state RELATED,ESTABLISHED -j ACCEPT
sudo firewall-cmd --reload
sudo systemctl restart libvirtd
```

> 重启后：KVM、虚拟网络、防火墙转发全部永久生效

## 二、准备 P4 镜像 & 解压
1. 把 `P4-Tutorials-Development-2026-04-01.ova` 放到 `~/公共`
2. 创建目录 + 正确解压（OVA 只用 tar，**不要用 unzip**）
```bash
mkdir -p ~/VM/P4-Tutorial
tar xvf ~/公共/P4-Tutorials-Development-2026-04-01.ova -C ~/VM/P4-Tutorial
```

---

## 三、一键官方转换（最关键，解决所有兼容问题）
1. 系统自带 `default` 存储池，无需新建，仅确保自启
```bash
sudo virsh pool-autostart default
```
2. 执行 **OVA 转 KVM 完整虚拟机**（唯一正确方式）
```bash
sudo virt-v2v -i ova ~/公共/P4-Tutorials-Development-2026-04-01.ova -o libvirt -os default
```
- 自动修复 GRUB、驱动、键鼠、显卡
- 自动导入到 virt-manager，无需手动配置

## 四、收尾清理（每次装好必做）
1. 打开「虚拟机管理器」
   - 删除**手动尝试创建的错误虚拟机** → 勾选「删除磁盘」
2. 宿主机清理残留文件
```bash
rm -rf ~/VM/P4-Tutorial
```

---

## 五、虚拟机固定优化（一次设置永久用）
选中 P4 虚拟机 → 设置：
1. **CPU/内存**：4核 + 4G 起步
2. **磁盘**：默认无需改动
3. **网卡**：
   - 网络：`default(NAT)`
   - 设备型号：`e1000`
4. **显示/显卡**：
   - 显卡类型：`QXL`
   - 显存：256MB
保存后开机。
