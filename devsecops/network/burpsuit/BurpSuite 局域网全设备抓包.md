# BurpSuite 局域网全设备抓包

适用：电脑、手机、模拟器、平板等**同一局域网内所有设备**，支持 HTTP + HTTPS 抓包，网页/APP 通用。

## 一、BurpSuite 服务端配置（电脑端，只需配置一次）

1. 打开 Burp → `Proxy` → `Settings(Options)`
2. 找到 `Proxy Listeners`，编辑默认监听器：
   - 绑定地址：改为 **All interfaces**（关键，允许局域网所有设备连接）
   - 端口：默认 **8080** 不变
3. 关闭拦截：`Proxy → Intercept` 改为 **Intercept is off**
   
   > 作用：不阻塞设备操作，只静默记录流量
   
   ## 二、查看电脑内网 IP（关键参数）
- Windows：cmd 执行 `ipconfig`，查看 WLAN/以太网 **IPv4 地址**（例：`192.168.1.105`）
- Linux/macOS：终端执行 `ifconfig` / `ip a`
  
  > 要求：所有待抓包设备，和电脑**连接同一个局域网**（同一路由器 WiFi/网段）
  
  ## 三、任意设备 统一代理配置（手机/模拟器/副机通用）
1. 设备连接和电脑**同一个 WiFi**
2. 修改 WiFi 网络 → 手动代理：
   - 代理主机/IP：填写**电脑的内网IP**
   - 代理端口：填写 **8080**
3. 保存配置，设备全部流量自动转发到 Burp
   
   ## 四、HTTPS 解密必备（必做，否则APP乱码/断网）
4. 在被抓包设备的浏览器访问：
   
   ```
   http://burp
   ```
5. 下载页面中的 **CA Certificate**（Burp 根证书）
6. 安装并**系统级信任证书**
   - 安卓：安装为「CA 根证书」
   - iOS：安装描述文件 + 手动开启证书信任
     
     > HTTP 流量可不装证书；**APP 绝大多数必须装证书**
     
     ## 五、开始抓包
7. 设备正常打开网页/APP，操作登录、签到、浏览等流程
8. Burp 中打开 `Proxy → HTTP history`
9. 可查看、筛选、复制所有请求：URL、请求头、Cookie、Token、请求参数、响应数据

---

# 核心原理复盘

1. `All interfaces`：让Burp监听全网卡，不止本机127.0.0.1；
2. 手动代理：局域网设备把流量转发给 Burp 中转；
3. Burp CA证书：中间人解密 HTTPS 加密流量；
4. 全程无差别捕获：局域网内所有走代理的设备流量全部抓取。

---

# 高频避坑点（复盘必记）

1. 不同WiFi/不同网段 → 代理不通，抓不到包；
2. 只装证书但未**系统信任** → HTTPS 报错、握手失败；
3. 开启拦截（Intercept is on）→ 设备网络卡顿、加载卡死；
4. 部分APP 开启 **SSL 证书锁定** → 普通抓包失效，需要额外绕过工具；
5. 电脑防火墙拦截8080端口 → 设备无法联网。

---

# 极简一句话浓缩版（快速回忆）

Burp开全网卡监听8080 → 设备同网段设电脑IP:8080代理 → 设备安装并信任Burp证书 → 正常操作即可全局抓包。


给你一份**极简复盘版、反向复原操作**，抓包结束后一键恢复正常，避免后续上网异常、安全残留。

## 一、必做操作（优先级最高，不做会断网）
### 1. 手机/所有抓包设备：关闭手动代理
进入连接的 WiFi 设置
- 代理：从「手动」改回 **无代理 / 自动**
✅ 作用：设备流量不再转发到 Burp，恢复正常上网，**不开Burp也能正常用网**

---

## 二、安全清理（建议必做）
### 2. 设备删除 Burp 根证书
防止长期留存陌生根证书，存在安全风险
- 安卓：设置 → 安全 → 信任的凭据 → 用户证书，删除 `PortSwigger` 证书
- iPhone：设置 → 通用 → VPN与设备管理，删除Burp描述文件；同时关闭证书信任

---

## 三、Burp 端清理（可选）
1. `Proxy → HTTP history` 清空抓包记录，避免杂乱
2. **无需修改监听配置**（`All interfaces:8080` 放着没关系），下次抓包直接用
3. 不需要抓包时，直接关闭 Burp 即可

---

## 四、常见后遗症提醒
1. **忘了关代理**：电脑没开 Burp → 手机完全断网、加载失败
2. **不删证书**：日常上网无影响，但长期留存中间人证书不安全
3. 电脑防火墙无需改动，无需关闭端口放行

---

## 超浓缩记忆版
1. 手机关闭 WiFi 手动代理
2. 删除设备上的 Burp CA 证书
3. 清空 Burp 历史记录，关闭软件
环境完全还原，和抓包前一模一样。
