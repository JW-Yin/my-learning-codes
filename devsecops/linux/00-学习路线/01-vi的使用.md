### 一、模式切换

| 命令 | 英文全称 | 功能说明 |
|------|----------|----------|
| `i` | **i**nsert | 光标前插入 |
| `I` | **I**nsert at beginning | 行首插入 |
| `a` | **a**ppend | 光标后追加 |
| `A` | **A**ppend at end | 行尾追加 |
| `o` | **o**pen below | 下方新起一行插入 |
| `O` | **O**pen above | 上方新起一行插入 |
| `Esc` | | 回到普通模式 |
| `v` | **v**isual | 字符可视化选择 |
| `V` | **V**isual line | 行可视化选择 |

---

### 二、光标移动

| 命令 | 助记 | 功能 |
|------|------|------|
| `h` / `j` / `k` / `l` | 左/下/上/右（历史布局） | 基本移动 |
| `w` | **w**ord | 下一单词开头 |
| `b` | **b**ack | 上一单词开头 |
| `e` | **e**nd | 单词末尾 |
| `0` | 行最左 | 移动到行首（硬行首） |
| `^` | 正则行首 | 移动到本行第一个非空字符 |
| `$` | 正则行尾 | 移动到行尾 |
| `gg` | **g**o top | 跳转到文件首行 |
| `G` | **G**o bottom | 跳转到文件末尾行 |
| `:n` | **n**umber | 跳转到第 n 行，如 `:25` |
| `Ctrl+f` | **f**orward | 向下翻一页 |
| `Ctrl+b` | **b**ackward | 向上翻一页 |

### 三、编辑（删除、修改、撤销）

| 命令 | 英文/助记 | 功能 |
|------|-----------|------|
| `x` | e**x**punge | 删除光标处字符 |
| `dd` | **d**elete line | 删除整行（同时复制） |
| `dw` | **d**elete **w**ord | 删至单词末尾 |
| `d$` 或 `D` | delete to end | 删至行尾 |
| `cw` | **c**hange **w**ord | 修改一个单词（删完进插入） |
| `c$` 或 `C` | change to end | 修改到行尾 |
| `r` | **r**eplace | 替换单个字符，如 `ra` |
| `R` | **R**eplace mode | 连续替换（覆盖模式） |
| `s` | **s**ubstitute | 删光标字符并进入插入（等价`xi`） |
| `S` | **S**ubstitute line | 删除整行并进入插入 |
| `~` | | 切换字符大小写 |
| `u` | **u**ndo | 撤销 |
| `Ctrl+r` | **r**edo | 重做 |
| `.` | | 重复上一次编辑操作（超级高频） |

---

### 四、复制与粘贴

| 命令 | 英文/助记 | 功能 |
|------|-----------|------|
| `yy` | **y**ank line | 复制整行 |
| `yw` | **y**ank **w**ord | 复制一个单词 |
| `y$` | yank to end | 复制到行尾 |
| `p` | **p**ut / **p**aste | 在光标后粘贴 |
| `P` | **P**ut before | 在光标前粘贴 |
| （可视模式选中后）`y` | yank | 复制选中文本 |
| （可视模式选中后）`d` | delete | 剪切选中文本 |

---

### 五、搜索与替换

| 命令 | 英文/助记 | 功能 |
|------|-----------|------|
| `/关键词` | | 向下搜索关键词 |
| `?关键词` | | 向上搜索关键词 |
| `n` | **n**ext | 下一个匹配项 |
| `N` | previous **N**ext | 上一个匹配项 |
| `:s/旧/新/` | **s**ubstitute | 替换当前行第一个匹配 |
| `:s/旧/新/g` | **g**lobal | 替换当前行所有匹配 |
| `:%s/旧/新/g` | % 全文件 | 全文替换 |
| `:%s/旧/新/gc` | **c**onfirm | 全文替换并逐个确认 |

---

### 六、文件与退出

| 命令 | 英文/助记 | 功能 |
|------|-----------|------|
| `:w` | **w**rite | 保存 |
| `:q` | **q**uit | 退出（未修改时） |
| `:q!` | quit force | 不保存强制退出 |
| `:wq` / `:x` | write quit / exit | 保存并退出 |
| `:e!` | edit! | 放弃所有修改，重新加载文件 |

---

### 七、窗口分割

| 命令 | 助记 | 功能 |
|------|------|------|
| `:sp 文件名` | **sp**lit | 水平分屏打开另一文件 |
| `:vsp 文件名` | **v**ertical **sp**lit | 垂直分屏打开另一文件 |
| `Ctrl+w w` | window switch | 在分割窗口间切换 |
| `:q` | | 关闭当前窗口 |
| `:only` | | 只保留当前窗口，关闭其他 |

---

### 八、常用设置

| 命令 | 功能 |
|------|------|
| `:set nu` | 显示行号 |
| `:set nonu` | 隐藏行号 |
| `:syntax on` | 开启语法高亮 |
