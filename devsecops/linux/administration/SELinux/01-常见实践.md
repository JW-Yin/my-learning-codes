# 实战 1：查看 SELinux 当前状态（最基础）
## 命令1：完整状态
```bash
sestatus
```

### 你会看到类似：
```
SELinux status:                 enabled
SELinuxfs mount:                /sys/fs/selinux
SELinux root directory:         /etc/selinux
Loaded policy name:             targeted
Current mode:                   enforcing
Mode from config file:          enforcing
Policy MLS status:              enabled
Policy deny_unknown status:      allowed
Memory protection checking:     actual (secure)
Max kernel policy version:      34
```

### 重点只看 3 个：
- `enabled`：SELinux 开启
- `targeted`：只对重点服务做限制（桌面/服务器默认）
- `enforcing`：**强制模式**（拦截+日志）

---

## 命令2：只看模式
```bash
getenforce
```
输出：`Enforcing` / `Permissive` / `Disabled`

# 实战 2：查看「安全上下文」（标签）
## ① 看文件标签
```bash
ls -Z ~/
```

输出示例：
```
unconfined_u:object_r:user_home_t:s0 Desktop
unconfined_u:object_r:user_home_t:s0 Documents
```

格式：`user:role:type:level`
**99% 看第三个：type（类型）**
- `user_home_t`：用户家目录类型

---

## ② 看进程标签
```bash
ps -Z | head
```

输出示例：
```
system_u:system_r:sshd_t:s0-s0:c0.c1023  1234 ?  00:00:00 sshd
unconfined_u:unconfined_r:unconfined_t:s0 5678 pts/0 00:00:00 bash
```

- `sshd_t`：SSH 服务进程域（被严格限制）
- `unconfined_t`：你自己的 shell（不受限，类似传统权限）

# 实战 3：临时切换 SELinux 模式（调试必备）
## ① 切到宽容模式（只记录不拦截）
```bash
sudo setenforce 0
getenforce  # 查看：Permissive
```

## ② 切回强制模式（正式安全）
```bash
sudo setenforce 1
getenforce  # 查看：Enforcing
```

> 注意：`setenforce` **临时生效，重启失效**

# 实战 4：查看 SELinux 拦截日志（AVC 拒绝）
这是**排错核心**。

## 方法1：直接搜 AVC
```bash
sudo journalctl -t SELinux
# 或
sudo cat /var/log/audit/audit.log | grep avc | tail
```

出现关键字：
- `denied`：被拒绝
- `scontext`：进程标签
- `tcontext`：目标文件标签
- `comm`：进程名（如 httpd、nginx）

## 方法2：工具自动分析（推荐）
```bash
# 没装就装
sudo dnf install setroubleshoot-server audit

# 分析最近拒绝
sudo ausearch -m avc -ts recent
```

# 实战 5：最常用操作 → 给目录设置正确标签（必学）
**场景**：你把网站放在 `/myweb`，不是默认 `/var/www/html`，Apache 读不了，因为标签不对。

## ① 创建目录
```bash
sudo mkdir /myweb
echo "test" | sudo tee /myweb/index.html
```

## ② 查看当前错误标签
```bash
ls -Zd /myweb
```
输出大概率是：`default_t` 或 `etc_t`，Apache 不能读。

## ③ 永久正确标签（标准做法）
```bash
# 1. 添加规则：/myweb 及其下所有文件 = httpd_sys_content_t
sudo semanage fcontext -a -t httpd_sys_content_t "/myweb(/.*)?"

# 2. 应用规则（恢复正确标签）
sudo restorecon -Rv /myweb
```

## ④ 验证
```bash
ls -Zd /myweb
```
输出：`httpd_sys_content_t` → 成功。

> 对比：`chcon` 是临时改标签，重启/重新标记就丢，**永远优先用 semanage + restorecon**

# 实战 6：SELinux 布尔值（开关，快速放行功能）
## ① 查看 httpd 相关开关
```bash
getsebool -a | grep httpd
```

## ② 开启 httpd 外联（比如爬虫、API 请求）
```bash
sudo setsebool -P httpd_can_network_connect on
```
- `-P`：**永久生效**（不加只临时）

---

# 实战 7：永久修改 SELinux 模式（谨慎）
```bash
sudo vim /etc/selinux/config
```

修改：
```ini
SELINUX=enforcing  # enforcing / permissive / disabled
SELINUXTYPE=targeted
```

**必须重启生效**：
```bash
sudo reboot
```
