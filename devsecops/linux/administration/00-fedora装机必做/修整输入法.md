
# Fedora 43 KDE 装机后输入法「100%成功」完整流程

---

## 第一步：终端执行所有命令（一次性复制执行）
```bash
# 1. 安装Fcitx5全套组件（如果之前没装过）
sudo dnf install fcitx5 fcitx5-chinese-addons kcm-fcitx5 fcitx5-gtk3 fcitx5-gtk4 fcitx5-qt5 fcitx5-qt6 -y

# 2. 彻底清理IBus残留进程和用户级配置（关键！）
pkill -9 ibus
rm -f ~/.config/plasma-workspace/env/ibus.sh ~/.xinputrc ~/.pam_environment
sed -i '/GTK_IM_MODULE/d' ~/.bashrc ~/.bash_profile ~/.profile ~/.zshrc 2>/dev/null || true
sed -i '/QT_IM_MODULE/d' ~/.bashrc ~/.bash_profile ~/.profile ~/.zshrc 2>/dev/null || true
sed -i '/XMODIFIERS/d' ~/.bashrc ~/.bash_profile ~/.profile ~/.zshrc 2>/dev/null || true
sed -i '/INPUT_METHOD/d' ~/.bashrc ~/.bash_profile ~/.profile ~/.zshrc 2>/dev/null || true

# 3. 配置【系统级】全局环境变量
sudo tee /etc/environment << 'EOF'
GTK_IM_MODULE=fcitx5
QT_IM_MODULE=fcitx5
XMODIFIERS=@im=fcitx5
INPUT_METHOD=fcitx5
SDL_IM_MODULE=fcitx5
GLFW_IM_MODULE=ibus
EOF

# 4. 配置【KDE会话专属】环境变量（Wayland下必做！这次成功的核心！）
mkdir -p ~/.config/plasma-workspace/env/
tee ~/.config/plasma-workspace/env/fcitx5.sh << 'EOF'
#!/bin/bash
export GTK_IM_MODULE=fcitx5
export QT_IM_MODULE=fcitx5
export XMODIFIERS=@im=fcitx5
export INPUT_METHOD=fcitx5
export SDL_IM_MODULE=fcitx5
export GLFW_IM_MODULE=ibus
EOF
chmod +x ~/.config/plasma-workspace/env/fcitx5.sh

# 5. 刷新仓库缓存
sudo dnf makecache
```

---

## 第二步：KDE图形化设置（2个关键位置）
1.  **系统设置 → 输入设备 → 虚拟键盘**
    - 下拉选择 **Fcitx5**，点击「应用」
2.  **系统设置 → 区域设置 → 输入源**
    - 点击「添加」，先加 **英语（美国）**，再加 **中文（智能拼音）**
    - 把切换快捷键设置为 **Super+Space（Win键+空格）**

---

## 第三步：重启系统（必须！）
```bash
sudo reboot
```

---

## 第四步：验证成功（和我们这次一样）
打开终端执行：
```bash
echo $INPUT_METHOD $GTK_IM_MODULE $QT_IM_MODULE $XMODIFIERS
```
✅ **成功标准**：输出必须是
```
fcitx5 fcitx5 fcitx5 @im=fcitx5
```

---

## 补充说明
1.  **为什么要加第4步的KDE专属环境变量？**
    这是Fedora 43 KDE Wayland下的关键——KDE会话启动时，会优先读取`~/.config/plasma-workspace/env/`目录下的脚本，只改`/etc/environment`有时会在Wayland下失效。
2.  **sed命令后面加了`2>/dev/null || true`**
    这是为了避免像这次一样出现「找不到文件」的报错，让命令更稳健。
3.  **Flatpak扩展**
    如果之后Flatpak软件无法输入中文，再单独装扩展即可，不影响核心配置。
