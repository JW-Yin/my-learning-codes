# Fedora 快速搭建 KVM+Windows 虚拟机（含网络终极修复）**全流程复刻版**
（纯命令+关键配置，换任何 Fedora 直接复制跑，10分钟搞定）

## 一、安装 KVM + Virt-Manager（核心一步）
```bash
# 安装全套虚拟化组件
sudo dnf install @virtualization -y

# 开机自启libvirtd服务
sudo systemctl enable --now libvirtd

# 给当前用户加权限（不用sudo也能管理虚拟机）
sudo usermod -aG libvirt $USER
```
**重启电脑** → 打开「Virtual Machine Manager」即可用

## 二、修复 KVM 默认网络（必做，解决无网）
```bash
# 定义默认NAT网络
sudo virsh net-define --file <(cat <<EOF
<network>
  <name>default</name>
  <forward mode='nat'/>
  <bridge name='virbr0' stp='on' delay='0'/>
  <ip address='192.168.122.1' netmask='255.255.255.0'>
    <dhcp>
      <range start='192.168.122.2' end='192.168.122.254'/>
    </dhcp>
  </ip>
</network>
EOF
)

# 启动+开机自启网络
sudo virsh net-start default
sudo virsh net-autostart default
```

## 三、虚拟机网卡关键配置（关机后改）
1. 关闭Windows虚拟机 → 右键「编辑」→ 网卡（NIC）
2. 配置：
   - 网络源：**虚拟网络 default:NAT**
   - 设备型号：**e1000**（Windows兼容最好，无驱动问题）
   - 勾选「启动时连接」

## 四、WiFi环境终极网络修复（你踩坑的核心）
**Fedora用WiFi时，KVM默认不转发流量，执行这1条必通**
```bash
# 手动给无线网卡加NAT转发（wlp1s0是你的WiFi名，通用不改）
sudo iptables -t nat -A POSTROUTING -s 192.168.122.0/24 -o wlp1s0 -j MASQUERADE

# 放行虚拟机转发流量
sudo iptables -A FORWARD -s 192.168.122.0/24 -j ACCEPT
sudo iptables -A FORWARD -d 192.168.122.0/24 -j ACCEPT
```

## 五、永久保存规则（重启不失效）
```bash
# 安装规则持久化工具
sudo dnf install iptables-services -y

# 保存当前所有网络规则
sudo service iptables save

# 开机自动加载规则
sudo systemctl enable --now iptables
```

## 六、验证网络（开机Windows即通）
Windows内执行：
```cmd
ping 8.8.8.8
```
✅ 通了 → 直接装QQ/微信/Office
