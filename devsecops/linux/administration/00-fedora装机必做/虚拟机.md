# 它由 4 个东西组成（不用记，懂意思就行）
1. **KVM**
   - 直接嵌在 **Linux 内核里** 的虚拟化引擎
   - 靠 CPU 硬件加速（Intel VT-x / AMD-V）
   → **速度接近物理机**，几乎无性能损耗

2. **QEMU**
   - 模拟“虚拟电脑”的硬件：主板、显卡、硬盘、网卡
   - 配合 KVM = 飞一般的虚拟机

3. **libvirt**
   - 统一管理接口，让工具能控制虚拟机
   - 相当于“虚拟机操作系统”

4. **Virt-Manager**
   - **图形界面控制面板**
   - 点鼠标就能：新建虚拟机、装系统、开机关机、调内存CPU、挂U盘

**你可以理解成：**
> KVM = 发动机
> QEMU = 车身
> libvirt = 底盘电控
> Virt-Manager = 方向盘+仪表盘

# 超简安装（Fedora 复制即跑）
```bash
sudo dnf install @virtualization
sudo systemctl enable --now libvirtd
sudo usermod -aG libvirt $USER
```
**重启** → 搜 `Virtual Machine Manager` 打开就能用。
