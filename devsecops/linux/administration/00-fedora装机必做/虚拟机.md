# Fedora KVM+Windows虚拟机 全机器通用一键部署手册
（**无坑永久生效版**，换任何Fedora主机直接复制执行，10分钟搞定，重启/换WiFi/换有线永不掉网）

---

## 一、前置必看（10秒确认）
1. 兼容范围：Fedora 39+ 全版本（含你当前的Fedora 43）
2. 必做前提：BIOS/UEFI中已开启CPU虚拟化（Intel VT-x / AMD-V）
3. 全程无需手动修改任何参数，所有命令直接复制粘贴执行即可

---

## 二、步骤1：前置虚拟化检查（避免白忙活）
执行以下命令，**输出结果大于0**=虚拟化已开启，可继续；等于0=需重启电脑进BIOS开启虚拟化
```bash
egrep -c '(vmx|svm)' /proc/cpuinfo
```

---

## 三、步骤2：一键安装KVM核心组件+权限配置
```bash
# 安装Fedora官方全套虚拟化组件
sudo dnf install @virtualization -y

# 启用libvirtd服务并设置开机自启
sudo systemctl enable --now libvirtd

# 给当前用户授予虚拟机管理权限（无需sudo就能操作）
sudo usermod -aG libvirt $USER
```
⚠️  **执行完必须重启电脑**（让用户权限生效，这步不能省）

---

## 四、步骤3：一键创建并启用KVM默认NAT网络
```bash
# 定义标准default NAT网络
sudo virsh net-define --file <(cat <<EOF
<network>
  <name>default</name>
  <forward mode='nat'/>
  <bridge name='virbr0' stp='on' delay='0'/>
  <ip address='192.168.122.1' netmask='255.255.255.0'>
    <dhcp>
      <range start='192.168.122.2' end='192.168.122.254'/>
    </dhcp>
  </ip>
</network>
EOF
)

# 启动网络+设置开机自启
sudo virsh net-start default
sudo virsh net-autostart default

# 验证网络状态（执行后能看到default为「活动+自启」即为正常）
sudo virsh net-list --all
```

---

## 五、步骤4：终极网络永久修复（核心·WiFi/有线全兼容）
彻底解决原教程iptables冲突、硬编码网卡名、重启掉网的问题，采用Fedora官方推荐的firewalld方案
```bash
# 1. 清理冲突的iptables服务（必做，解决防火墙规则冲突）
sudo systemctl stop iptables
sudo systemctl disable iptables
sudo dnf remove iptables-services -y

# 2. 开启系统IP永久转发（重启不失效）
echo "net.ipv4.ip_forward=1" | sudo tee /etc/sysctl.d/99-kvm-forward.conf
sudo sysctl -p /etc/sysctl.d/99-kvm-forward.conf

# 3. 自动识别当前主机的出口网卡（WiFi/有线通用，无需手动改网卡名）
NIC=$(ip route get 1.1.1.1 | awk '{print $5}')

# 4. firewalld永久NAT转发规则（Fedora官方标准方案，重启不丢）
sudo firewall-cmd --permanent --zone=trusted --add-interface=virbr0
sudo firewall-cmd --permanent --add-masquerade
sudo firewall-cmd --permanent --direct --add-rule ipv4 filter FORWARD 0 -i virbr0 -o $NIC -j ACCEPT
sudo firewall-cmd --permanent --direct --add-rule ipv4 filter FORWARD 0 -i $NIC -o virbr0 -m state --state RELATED,ESTABLISHED -j ACCEPT

# 5. 重载规则生效
sudo firewall-cmd --reload
sudo systemctl restart libvirtd
```

## 六、步骤5：Windows虚拟机网卡标准配置（无驱动坑）
1. 先关闭Windows虚拟机（关机状态下才能修改网卡配置）
2. 打开Virtual Machine Manager → 右键虚拟机 → 「编辑」
3. 找到左侧「网卡(NIC)」，按以下标准配置：
   - 网络源：**虚拟网络 default:NAT**
   - 设备型号：**e1000**（Windows全版本兼容，无需额外装驱动）
   - 勾选「启动时连接」
4. 点击「应用」保存配置

---

## 七、步骤6：网络验证&开机测试
1. 启动Windows虚拟机
2. 打开Windows命令提示符(CMD)，执行以下命令：
```cmd
ping 8.8.8.8
```
✅ 能正常ping通=网络完全正常，可正常安装软件、上网

## 【故障快速排查】万一没网，30秒定位问题
1. 检查KVM网络状态：`sudo virsh net-list --all` → 确保default是活动+自启
2. 检查IP转发是否生效：`cat /proc/sys/net/ipv4/ip_forward` → 输出1为正常
3. 检查virbr0网桥是否在线：`ip addr show virbr0` → 确保有192.168.122.1地址
4. 重载防火墙规则：`sudo firewall-cmd --reload && sudo systemctl restart libvirtd`

磁盘空间扩容
# 1. 先确认磁盘信息（可选，用来核对路径和格式）
sudo qemu-img info /var/lib/libvirt/images/ubuntu20.04-1.qcow2

# 2. 扩容磁盘！比如从25G扩到40G（可以改成30G/50G，推荐至少30G满足P4开发）
sudo qemu-img resize /var/lib/libvirt/images/ubuntu20.04-1.qcow2 40G
