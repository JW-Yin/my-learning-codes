### 核心概念铺垫
在开始前，先明确两个基础概念：
- **标准输入 (stdin)**：代码 `0`，命令接收输入的地方（默认是键盘）。
- **标准输出 (stdout)**：代码 `1`，命令正常执行的输出（默认是终端屏幕）。
- **标准错误 (stderr)**：代码 `2`，命令执行出错的提示（默认也是终端屏幕）。

重定向/管道的本质，就是改变这些输入/输出的默认位置。

---

## 1. 管道 `|`
### 作用
把**前一个命令的标准输出**，直接作为**后一个命令的标准输入**，实现命令“串联”执行。
### 语法
```bash
命令1 | 命令2
```
### 示例（最常用）
```bash
# 示例1：查看当前目录下的文件，只筛选包含 .txt 的行
ls | grep .txt

# 示例2：统计当前目录下的文件总数（wc -l 统计行数）
ls | wc -l

# 示例3：查看系统进程，筛选包含 python 的进程，再按行号排序
ps aux | grep python | sort -n
```
### 关键说明
- 管道只传递 `stdout`（标准输出），不会传递 `stderr`（错误输出）。
- 管道可以无限串联（如 `命令1 | 命令2 | 命令3`）。

---

## 2. 覆盖重定向 `>`
### 作用
将命令的**标准输出**写入指定文件，**覆盖文件原有内容**（如果文件不存在则创建）。
### 语法
```bash
命令 > 文件名
```
### 示例
```bash
# 示例1：把 ls 的输出写入 filelist.txt，覆盖原有内容
ls > filelist.txt

# 示例2：清空一个文件（空命令 > 文件）
> empty.txt
```
### 补充
如果想重定向**标准错误**到文件，需要指定错误码 `2`：
```bash
# 故意执行错误命令，把错误提示写入 error.log
ls /xxx 2> error.log
```

---

## 3. 追加重定向 `>>`
### 作用
将命令的**标准输出**追加到指定文件末尾，**不会覆盖原有内容**（文件不存在则创建）。
### 语法
```bash
命令 >> 文件名
```
### 示例
```bash
# 示例1：把当前时间追加到 log.txt 末尾（对比 > 会覆盖）
date >> log.txt

# 示例2：先写入一行文字，再追加一行
echo "开始记录日志：" > log.txt
echo "执行时间：$(date)" >> log.txt
```

---

## 4. 混合重定向 `2>&1`
### 作用
把**标准错误 (2)** 重定向到**标准输出 (1)** 的位置（通俗说：让错误信息和正常信息走同一条路）。
### 语法
```bash
命令 > 文件名 2>&1  # 正常输出+错误输出都写入文件（覆盖）
命令 >> 文件名 2>&1 # 正常输出+错误输出都追加到文件
```
### 示例
```bash
# 示例1：执行可能出错的命令，把正常/错误输出都写入 log.txt（覆盖）
ls /xxx /home > log.txt 2>&1

# 示例2：追加模式（更常用，避免覆盖历史日志）
python test.py >> run.log 2>&1
```
### 简化写法（bash 4.0+ 支持）
```bash
# 等价于 > log.txt 2>&1
command &> log.txt

# 等价于 >> log.txt 2>&1
command &>> log.txt
```

---

## 5. 分流命令 `tee`
### 作用
“分流”输出：既把内容输出到**终端屏幕**，又把内容**写入/追加到文件**（解决 `>` 重定向后看不到终端输出的问题）。
### 语法
```bash
命令 | tee 文件名        # 写入文件（覆盖）+ 输出到屏幕
命令 | tee -a 文件名     # 追加到文件 + 输出到屏幕
```
### 示例
```bash
# 示例1：查看 ls 输出的同时，把内容写入 filelist.txt（覆盖）
ls | tee filelist.txt

# 示例2：追加模式，同时捕获正常+错误输出
python test.py 2>&1 | tee -a run.log
```
### 常用场景
执行耗时命令时，既想实时看输出，又想保存日志（比如部署脚本、运行程序）。

---

## 综合实战案例
用一个例子串联所有知识点，帮你理解实际用法：
```bash
# 需求：运行 Python 脚本，实时看输出、保存日志（正常+错误）、统计日志行数
# 步骤1：运行脚本，分流输出（屏幕+日志文件）
python app.py 2>&1 | tee -a app.log

# 步骤2：统计日志行数（用管道串联）
cat app.log | wc -l > log_count.txt

# 步骤3：把行数追加到日志末尾
echo "日志总行数：$(cat log_count.txt)" >> app.log
```

---

### 总结
1. **管道 `|`**：串联命令，前一个的输出 → 后一个的输入（只传正常输出）。
2. **重定向 `>`/`>>`**：覆盖/追加写入文件（默认只处理正常输出）。
3. **`2>&1`**：把错误输出合并到正常输出，实现“全量输出重定向”。
4. **`tee`**：分流输出，既看屏幕又存文件，解决重定向后看不到输出的问题。
