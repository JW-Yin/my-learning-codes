 
## 一、文件操作命令（ls/cd/cp/mv/rm/ln）
这类命令是 Bash 最基础的文件/目录管理工具，先掌握核心用法和避坑点。
 
### 1. ls（列出目录内容）
**核心作用**：查看当前/指定目录下的文件、目录信息
**常用选项**（可组合使用）：
- `-l`：以长格式显示（包含权限、大小、修改时间等详细信息）
- `-a`：显示隐藏文件（Linux 中以 `.` 开头的文件/目录是隐藏的）
- `-h`：人性化显示文件大小（如 100K、2M 而非字节数）
- `-t`：按修改时间降序排序
- `-r`：反向排序（搭配 `-t` 就是按修改时间升序）

**实战示例**：
```bash
ls                  # 查看当前目录的文件/目录（仅名称）
ls -lha             # 最常用组合：详细+显示隐藏+人性化大小
ls -lt /home        # 查看/home目录，按修改时间降序
ls -lh *.txt        # 只查看当前目录下所有.txt文件的详细信息
```

### 2. cd（切换工作目录）
**核心作用**：改变当前终端的工作目录
**常用快捷用法**（无需记复杂路径）：
```bash
cd ~                # 回到当前用户的家目录（等价于 cd）
cd ..               # 回到上一级目录（.. 代表父目录，. 代表当前目录）
cd -                # 回到上一次所在的目录（快速切换两个目录）
cd /usr/local/bin   # 绝对路径切换（从根目录开始）
cd ./docs           # 相对路径切换（相对于当前目录）
```

### 3. cp（复制文件/目录）
**核心作用**：复制文件或目录，注意目录需要加递归参数
**常用选项**：
- `-r`：递归复制目录（复制目录必须加这个）
- `-i`：覆盖文件前提示（避免误删）
- `-p`：保留文件属性（权限、修改时间等）
- `-v`：显示复制过程（可视化）

**实战示例**：
```bash
cp file1.txt file2.txt       # 复制file1.txt为file2.txt（同目录）
cp -i file1.txt /tmp/        # 复制到/tmp目录，覆盖前提示
cp -rp dir1 /home/           # 复制dir1目录到/home，保留属性
cp -v *.sh /usr/local/bin/   # 复制所有.sh文件，显示复制过程
```

### 4. mv（移动/重命名文件/目录）
**核心作用**：一个命令实现「移动」和「重命名」，目录无需递归
**常用选项**：
- `-i`：覆盖前提示
- `-v`：显示操作过程

**实战示例**：
```bash
mv file1.txt file2.txt       # 重命名（同目录下移动=重命名）
mv file1.txt /tmp/           # 移动文件到/tmp目录
mv -i dir1 /home/            # 移动目录到/home，覆盖前提示
mv *.log ./logs/             # 移动当前目录所有.log文件到logs子目录
```

### 5. rm（删除文件/目录）
**核心作用**：删除文件/目录，**极度注意：Linux 没有回收站，删除不可逆！**
**常用选项**：
- `-r`：递归删除目录（删除目录必须加）
- `-f`：强制删除（无提示，谨慎用）
- `-i`：删除前提示（安全模式）
- `-v`：显示删除过程

**实战示例**：
```bash
rm file1.txt                # 删除单个文件（默认有提示，视系统配置）
rm -i *.tmp                 # 删除所有.tmp文件，逐个提示（安全）
rm -r dir1                  # 删除dir1目录及所有内容（有提示）
rm -rf /tmp/test*           # 强制删除/tmp下test开头的所有文件/目录（谨慎！）
# 绝对禁止：rm -rf / （会删除系统所有文件，直接报废系统）
```

### 6. ln（创建链接）
**核心作用**：创建硬链接/软链接（软链接=Windows快捷方式，更常用）
**常用选项**：
- `-s`：创建软链接（符号链接），不加则默认创建硬链接

**实战示例**：
```bash
# 1. 硬链接（少用，不能跨文件系统、不能链接目录）
ln /etc/hosts hosts_hard    # 给/etc/hosts创建硬链接hosts_hard

# 2. 软链接（常用，建议用绝对路径，避免路径失效）
ln -s /usr/local/node/bin/node /usr/bin/node  # 给node命令创建软链接（全局可用）
ln -s /home/user/docs docs_link               # 给目录创建软链接
ls -l docs_link             # 查看软链接（会显示指向的原路径）
```

## 二、文本查看命令（cat/less/head/tail）
这类命令用于查看文本文件内容，不同场景选不同工具效率更高。

### 1. cat（一次性查看/拼接文件）
**核心作用**：一次性显示文件全部内容（适合小文件），或拼接多个文件
**常用选项**：
- `-n`：显示行号（包含空行）
- `-b`：只显示非空行的行号
- `-s`：压缩连续的空行（只留一行）

**实战示例**：
```bash
cat file.txt                # 查看file.txt全部内容
cat -n file.txt             # 带行号查看
cat file1.txt file2.txt > all.txt  # 拼接file1和file2到all.txt
cat -sb log.txt             # 查看log.txt，显示非空行号+压缩空行
```

### 2. less（分页查看大文件）
**核心作用**：分页浏览大文件（比 `more` 更强大），支持搜索、上下翻页
**常用操作**（进入less后）：
- 空格：下一页
- b：上一页
- /关键词：搜索关键词（n=下一个匹配，N=上一个匹配）
- q：退出less
- G：跳转到最后一行
- gg：跳转到第一行
- 数字+回车：跳转到指定行

**实战示例**：
```bash
less large_log.log          # 分页查看大日志文件
less -N large_log.log       # 显示行号的分页查看
```

### 3. head（查看文件开头）
**核心作用**：默认显示文件前10行，可指定行数
**常用选项**：
- `-n`：指定行数（如 `-n 20` 显示前20行，`-n -10` 显示除最后10行外的内容）

**实战示例**：
```bash
head file.txt               # 默认前10行
head -n 5 file.txt          # 前5行
head -n -50 file.txt        # 显示file.txt除最后50行外的所有内容
```

### 4. tail（查看文件结尾/实时监控）
**核心作用**：默认显示文件最后10行，最常用「实时监控日志」
**常用选项**：
- `-n`：指定行数（如 `-n 20` 显示最后20行）
- `-f`：实时跟踪文件变化（日志新增内容会自动显示）
- `-F`：比 `-f` 更稳定（文件被替换/重建也能继续跟踪）

**实战示例**：
```bash
tail file.txt               # 默认最后10行
tail -n 15 file.txt         # 最后15行
tail -f /var/log/syslog     # 实时监控系统日志（按Ctrl+C退出）
tail -F /var/log/nginx/access.log  # 监控nginx访问日志（生产环境常用）
```

## 三、查找命令（find/grep/locate）
### 1. find（实时精准查找文件/目录）
**核心作用**：递归查找符合条件的文件/目录，功能强大（按名称、大小、时间、用户等筛选）
**基本语法**：`find 查找路径 查找条件 操作`
**常用查找条件**：
- `-name "关键词"`：按名称查找（支持通配符 `*`/`?`）
- `-type`：按类型（f=文件，d=目录，l=软链接）
- `-size`：按大小（+10M=大于10M，-500K=小于500K，1G=等于1G）
- `-mtime`：按修改时间（-7=7天内，+30=30天前）
- `-user 用户名`：按所属用户查找

**实战示例**：
```bash
# 查找/home下所有.txt文件
find /home -name "*.txt"

# 查找/var下名称以log开头的目录
find /var -type d -name "log*"

# 查找根目录下大于1G的文件（排查大文件）
find / -size +1G -type f

# 查找当前目录3天内修改的.sh文件
find ./ -mtime -3 -type f -name "*.sh"

# 查找并删除/tmp下test开头的临时文件（{}代表匹配的文件，\;是固定结尾）
find /tmp -name "test*" -exec rm -f {} \;
```

### 2. grep（查找文本内容/过滤输出）
**核心作用**：在文件或命令输出中查找匹配的字符串/正则表达式（文本过滤神器）
**常用选项**：
- `-i`：忽略大小写
- `-n`：显示匹配行的行号
- `-v`：反向匹配（显示不包含关键词的行）
- `-r`：递归查找目录下的所有文件
- `-E`：支持扩展正则表达式（如 `|` 表示或）

**实战示例**：
```bash
# 查找log.txt中包含"error"的行
grep "error" log.txt

# 忽略大小写查找"ERROR"
grep -i "ERROR" log.txt

# 显示匹配行的行号
grep -n "warning" log.txt

# 显示不包含"info"的行（过滤无用日志）
grep -v "info" log.txt

# 递归查找/etc下包含"user1"的所有文件
grep -r "user1" /etc/

# 查找包含error或warning的行（扩展正则）
grep -E "error|warning" log.txt

# 结合管道过滤命令输出（比如查看进程）
ps aux | grep nginx
```

### 3. locate（快速查找文件）
**核心作用**：比 `find` 快10倍以上，基于系统预建的文件数据库查找（缺点：非实时）
**注意**：新创建的文件默认查不到，需手动更新数据库：`sudo updatedb`

**常用选项**：
- `-i`：忽略大小写
- `-n`：限制结果数量

**实战示例**：
```bash
# 查找所有包含passwd的文件（比如配置文件）
locate passwd

# 忽略大小写查找nginx.conf
locate -i "nginx.conf"

# 只显示前10个.sh脚本文件
locate -n 10 "*.sh"

# 先更新数据库（查找新文件前）
sudo updatedb && locate new_file.txt
```
