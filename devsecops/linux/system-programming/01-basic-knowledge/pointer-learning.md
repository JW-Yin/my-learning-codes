## 第一组：常量指针 vs 指针常量
核心记忆法：**const 靠近谁，谁就不能被修改**

### 1. 常量指针（`const int *p`）
- **核心本质**：指针指向的「内容」是常量，不能通过指针修改，但指针本身可以指向其他地址。
- **通俗理解**：你手里的遥控器（指针p）可以换台（指向其他地址），但不能调节当前频道的音量（修改指向的内容）。

```c
#include <stdio.h>

int main() {
    int a = 10, b = 20;
    const int *p = &a;  // 常量指针
    
    // *p = 100;  ❌ 错误：不能修改指向的内容
    p = &b;            ✅ 正确：指针可以指向其他地址
    printf("*p = %d\n", *p);  // 输出：*p = 20
    return 0;
}
```

### 2. 指针常量（`int * const p`）
- **核心本质**：指针「本身」是常量，地址不能改（不能指向其他地方），但指向的内容可以修改。
- **通俗理解**：遥控器（指针p）被固定在某个频道（地址）不能换台，但可以调节当前频道的音量（修改内容）。

```c
#include <stdio.h>

int main() {
    int a = 10, b = 20;
    int * const p = &a;  // 指针常量
    
    *p = 100;          ✅ 正确：可以修改指向的内容
    // p = &b;        ❌ 错误：指针不能指向其他地址
    printf("*p = %d\n", *p);  // 输出：*p = 100
    return 0;
}
```

## 第二组：指针数组 vs 数组指针
核心记忆法：**优先级：[] > *，括号() 可以改变优先级**

### 1. 指针数组（`int *p[10]`）
- **核心本质**：首先是「数组」，数组里的每个元素都是 int 类型的指针。
- **通俗理解**：一个装了10个遥控器（指针）的盒子（数组），每个遥控器可以指向不同的电视（int变量）。

```c
#include <stdio.h>

int main() {
    int a = 10, b = 20, c = 30;
    int *p[3] = {&a, &b, &c};  // 指针数组：3个元素，每个都是int指针
    
    // 遍历指针数组，访问每个指针指向的内容
    for (int i = 0; i < 3; i++) {
        printf("*p[%d] = %d\n", i, *p[i]);
    }
    // 输出：
    // *p[0] = 10
    // *p[1] = 20
    // *p[2] = 30
    return 0;
}
```

### 2. 数组指针（`int (*p)[10]`）
- **核心本质**：首先是「指针」，这个指针专门指向一个「大小为10的int数组」。
- **通俗理解**：一个遥控器（指针p），只能指向一个装了10台电视的大柜子（长度为10的int数组），不能指向单台电视。

```c
#include <stdio.h>

int main() {
    int arr[3] = {10, 20, 30};  // 长度为3的int数组
    int (*p)[3] = &arr;         // 数组指针：指向长度为3的int数组
    
    // 访问数组内容：(*p)[i] 等价于 arr[i]
    for (int i = 0; i < 3; i++) {
        printf("(*p)[%d] = %d\n", i, (*p)[i]);
    }
    // 输出：
    // (*p)[0] = 10
    // (*p)[1] = 20
    // (*p)[2] = 30
    return 0;
}
```

## 第三组：指针函数 vs 函数指针
核心记忆法：**优先级：() > *，括号() 改变优先级**

### 1. 指针函数（`int* func()`）
- **核心本质**：首先是「函数」，函数的返回值是 int 类型的指针。
- **通俗理解**：一个加工厂（函数func），加工完成后输出一个遥控器（int指针），而不是直接输出数字。

```c
#include <stdio.h>

// 指针函数：返回int指针
int* get_num_ptr() {
    static int num = 100;  // 用static避免局部变量销毁
    return &num;
}

int main() {
    int *p = get_num_ptr();
    printf("*p = %d\n", *p);  // 输出：*p = 100
    return 0;
}
```

### 2. 函数指针（`int (*func)()`）
- **核心本质**：首先是「指针」，这个指针指向一个「返回值为int、无参数的函数」。
- **通俗理解**：一个遥控器（函数指针func），可以指向不同的加工厂（函数），按一下就能调用对应的加工厂。

```c
#include <stdio.h>

// 定义两个普通函数
int add() { return 1+2; }
int sub() { return 5-3; }

int main() {
    int (*func)();  // 函数指针：指向返回int、无参数的函数
    
    func = add;     // 指向add函数
    printf("add结果：%d\n", func());  // 输出：add结果：3
    
    func = sub;     // 指向sub函数
    printf("sub结果：%d\n", func());  // 输出：sub结果：2
    return 0;
}
```

---

### 总结（核心关键点）
1. **常量指针/指针常量**：看`const`位置——靠近类型（int）则内容不可改，靠近指针变量（p）则指针地址不可改。
2. **指针数组/数组指针**：看优先级——无括号`*p[10]`是数组（存指针），有括号`(*p)[10]`是指针（指向数组）。
3. **指针函数/函数指针**：看优先级——无括号`int* func()`是函数（返回指针），有括号`int (*func)()`是指针（指向函数）。
