# C 语言核心指针概念区别详解

## 总结对比表
| 分组         | 易混概念 1       | 核心主体 | 易混概念 2       | 核心主体 |
|--------------|------------------|----------|------------------|----------|
| 第一组       | 常量指针（`const int *p`） | 指向的内容不可改 | 指针常量（`int * const p`） | 指针本身不可改 |
| 第二组       | 指针数组（`int *p[10]`） | 数组（存指针） | 数组指针（`int (*p)[10]`） | 指针（指向数组） |
| 第三组       | 指针函数（`int* func()`） | 函数（返回指针） | 函数指针（`int (*func)()`） | 指针（指向函数） |
