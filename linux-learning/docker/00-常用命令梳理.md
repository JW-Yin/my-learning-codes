# Docker 常用命令全梳理（复盘专用）
## 一、镜像管理命令（核心：对「镜像模板」的操作）
| 命令 | 作用 | 格式/示例 | 关键注意点 |
|------|------|-----------|------------|
| `docker pull` | 从镜像仓库拉取镜像到本地 | 格式：`docker pull [--platform=架构] 镜像名:版本`<br>示例：<br>`docker pull nginx:latest`<br>`docker pull --platform=arm64 nginx` | 1. 省略版本默认拉取`latest`；<br>2. 国内需配置镜像加速站避免拉取失败；<br>3. 完整镜像地址：`仓库地址/命名空间/镜像名:版本`（可简化） |
| `docker images`/`docker image ls` | 列出本地所有镜像 | 格式：`docker images`<br>示例：`docker images nginx`（过滤nginx镜像） | 输出包含镜像ID、版本、大小等，可通过镜像ID前几位操作镜像 |
| `docker rmi` | 删除本地镜像 | 格式：`docker rmi [-f] 镜像名:版本/镜像ID`<br>示例：<br>`docker rmi nginx:latest`<br>`docker rmi -f a1b2c3d4e5f6`（强制删除） | 1. 镜像被容器使用时，需先删容器再删镜像；<br>2. `-f`强制删除（谨慎使用） |

## 二、容器生命周期管理命令（核心：容器的创建/启停/删除）
### 1. 核心启动命令：`docker run`（创建+启动容器）
| 核心参数 | 作用 | 示例片段 | 关键注意点 |
|----------|------|----------|------------|
| `-d` | 后台运行容器（分离模式） | `docker run -d nginx` | 不霸占终端，生产环境首选 |
| `--name` | 自定义容器名 | `docker run --name my-nginx nginx` | 容器名唯一，避免重复 |
| `--restart` | 容器重启策略 | `docker run --restart unless-stopped nginx` | 生产环境用`unless-stopped`（手动停止不重启）；`always`（任何情况都重启） |
| `--rm` | 容器停止后自动删除 | `docker run --rm -it ubuntu /bin/bash` | 适合临时调试容器 |
| `-it` | 分配交互式终端 | `docker run -it ubuntu /bin/bash` | 配合`/bin/bash`/`/bin/sh`进入容器 |
| `-p` | 端口映射（宿主机→容器） | `docker run -p 8080:80 nginx`<br>`docker run -p 127.0.0.1:8080:80 nginx` | 1. 格式：`宿主机IP:宿主机端口:容器端口`（IP可省略）；<br>2. 一个宿主机端口只能绑定一个容器 |
| `-v` | 目录/卷挂载（数据持久化） | 绑定挂载：`docker run -v ~/nginx/html:/usr/share/nginx/html nginx`<br>命名卷挂载：`docker run -v nginx_html:/usr/share/nginx/html nginx` | 1. 绑定挂载：宿主机路径需绝对路径，覆盖容器目录；<br>2. 命名卷：首次使用自动同步容器目录文件 |
| `-e` | 传递环境变量 | `docker run -e MONGO_INITDB_ROOT_USERNAME=admin mongo` | 容器支持的环境变量需查对应镜像文档 |

**完整示例**：
```bash
docker run -d \
  --name my-nginx \
  --restart unless-stopped \
  -p 80:80 \
  -v nginx_html:/usr/share/nginx/html \
  -e NGINX_ENV=prod \
  nginx:latest
```

### 2. 容器查看/启停/删除
| 命令 | 作用 | 格式/示例 | 关键注意点 |
|------|------|-----------|------------|
| `docker ps` | 查看运行中的容器 | `docker ps` | 输出容器ID、镜像、端口、状态等 |
| `docker ps -a` | 查看所有容器（含已停止） | `docker ps -a` | `-a`=all，排查容器启动失败问题常用 |
| `docker stop` | 停止运行中的容器 | `docker stop 容器名/容器ID`<br>示例：`docker stop my-nginx` | 优雅停止容器，释放资源 |
| `docker start` | 启动已停止的容器 | `docker start my-nginx` | 保留原启动参数（端口、挂载等），无需重新`run` |
| `docker restart` | 重启容器 | `docker restart my-nginx` | 支持运行中/已停止的容器 |
| `docker rm` | 删除容器 | 格式：`docker rm [-f] 容器名/容器ID`<br>示例：<br>`docker rm my-nginx`（先停止）<br>`docker rm -f my-nginx`（强制删除运行中容器） | 1. 需先停止容器（除非加`-f`）；<br>2. `docker container prune`：批量删除所有已停止容器 |

## 三、容器调试/操作命令（排查问题/内部操作）
| 命令 | 作用 | 格式/示例 | 关键注意点 |
|------|------|-----------|------------|
| `docker logs` | 查看容器运行日志 | 格式：`docker logs [-f] 容器名/容器ID`<br>示例：<br>`docker logs my-nginx`<br>`docker logs -f my-nginx`（实时滚动） | 排查容器启动/运行异常的核心命令 |
| `docker inspect` | 查看容器/镜像/卷/网络的详细信息 | `docker inspect my-nginx` | 输出JSON格式，包含端口、挂载、IP、环境变量等（忘记启动参数时用） |
| `docker exec` | 在运行中容器内执行命令 | 格式：`docker exec -it 容器名/容器ID 命令`<br>示例：<br>`docker exec -it my-nginx /bin/bash`<br>`docker exec -it my-nginx cat /etc/nginx/nginx.conf` | 1. `-it`必加（交互式）；<br>2. 轻量镜像用`/bin/sh`替代`/bin/bash` |
| `docker cp` | 宿主机↔容器互传文件 | 宿主机→容器：`docker cp 宿主机路径 容器名:容器路径`<br>容器→宿主机：`docker cp 容器名:容器路径 宿主机路径`<br>示例：<br>`docker cp ~/index.html my-nginx:/usr/share/nginx/html` | 无需进入容器，直接传输文件 |

## 四、数据卷管理命令（持久化核心）
| 命令 | 作用 | 格式/示例 | 关键注意点 |
|------|------|-----------|------------|
| `docker volume create` | 创建命名卷 | `docker volume create nginx_html` | Docker自动管理存储路径（默认`/var/lib/docker/volumes/`） |
| `docker volume ls` | 列出所有命名卷 | `docker volume ls` | 区分绑定挂载（无记录）和命名卷 |
| `docker volume inspect` | 查看卷的详细信息 | `docker volume inspect nginx_html` | 可查卷的真实存储路径 |
| `docker volume rm` | 删除命名卷 | `docker volume rm nginx_html` | 需先解除容器与卷的关联 |
| `docker volume prune -a` | 删除所有未使用的卷 | `docker volume prune -a` | 清理无用数据，释放磁盘空间 |

## 五、网络管理命令（容器通信）
| 命令 | 作用 | 格式/示例 | 关键注意点 |
|------|------|-----------|------------|
| `docker network ls` | 列出所有网络（默认+自定义） | `docker network ls` | 包含bridge（默认）、host、none、自定义网桥 |
| `docker network create` | 创建自定义网桥 | `docker network create network1` | 同一网桥内容器可通过容器名DNS解析通信 |
| `docker network rm` | 删除自定义网桥 | `docker network rm network1` | 需先移除网桥内的所有容器 |
| `docker network inspect` | 查看网络详细信息 | `docker network inspect network1` | 可查网桥内的容器、IP段等 |
| `docker run --network` | 容器加入指定网络 | `docker run -d --network network1 --name mongo_db mongo` | 多容器通信首选自定义网桥 |

## 六、镜像构建与分发（Dockerfile相关）
| 命令 | 作用 | 格式/示例 | 关键注意点 |
|------|------|-----------|------------|
| `docker build` | 基于Dockerfile构建镜像 | 格式：`docker build -t 镜像名:版本 构建上下文路径`<br>示例：`docker build -t my-fastapi:v1.0 .` | 1. `-t`：给镜像打标签；<br>2. `.`：当前目录为构建上下文（查找Dockerfile） |
| `docker login` | 登录Docker Hub（或私有仓库） | `docker login` | 按提示输入用户名/密码，完成认证 |
| `docker tag` | 给镜像重命名（推送前必备） | 格式：`docker tag 原镜像名:版本 仓库用户名/镜像名:版本`<br>示例：`docker tag my-fastapi:v1.0 techshrimp/my-fastapi:v1.0` | 推送镜像必须带仓库用户名（命名空间） |
| `docker push` | 推送镜像到仓库 | 格式：`docker push 仓库用户名/镜像名:版本`<br>示例：`docker push techshrimp/my-fastapi:v1.0` | 推送前需确保已登录+镜像标签正确 |

## 七、Docker Compose命令（多容器编排）
| 命令 | 作用 | 格式/示例 | 关键注意点 |
|------|------|-----------|------------|
| `docker compose up -d` | 启动compose文件中所有容器 | `docker compose up -d`（默认读docker-compose.yml）<br>`docker compose -f my-compose.yml up -d`（指定文件） | `-d`后台运行，自动创建专属网桥 |
| `docker compose down` | 停止并删除所有容器+网桥 | `docker compose down` | 会删除容器，但保留命名卷（数据不丢） |
| `docker compose stop` | 仅停止所有容器（不删除） | `docker compose stop` | 容器、网桥都保留，可通过`start`重启 |
| `docker compose start` | 启动已停止的compose容器 | `docker compose start` | 保留原配置，快速恢复运行 |
| `docker compose logs` | 查看compose容器日志 | `docker compose logs -f`（实时查看所有容器）<br>`docker compose logs -f 服务名`（指定服务） | 排查多容器协作问题常用 |

## 八、系统清理与信息查看（运维必备）
| 命令 | 作用 | 格式/示例 | 关键注意点 |
|------|------|-----------|------------|
| `docker --version` | 查看Docker版本 | `docker --version` | 快速验证Docker是否安装成功 |
| `docker info` | 查看Docker系统详细信息 | `docker info` | 包含镜像数、容器数、存储驱动、镜像加速配置等 |
| `docker container prune` | 清理所有已停止的容器 | `docker container prune` | 释放容器占用的资源 |
| `docker image prune` | 清理所有无标签（<none>）镜像 | `docker image prune` | 避免无用镜像占用磁盘 |
| `docker system prune` | 清理所有未使用的镜像/容器/网络/卷 | `docker system prune` | 谨慎使用，会删除所有无用资源 |

## 九、快速复盘清单（核心命令速记）
| 功能场景 | 核心命令 |
|----------|----------|
| 拉取镜像 | `docker pull 镜像名:版本` |
| 启动容器 | `docker run -d --name 容器名 -p 宿端口:容端口 -v 宿路径:容路径 镜像名` |
| 查看容器 | `docker ps`（运行中）/ `docker ps -a`（所有） |
| 启停容器 | `docker stop/start 容器名` |
| 进入容器 | `docker exec -it 容器名 /bin/bash` |
| 查看日志 | `docker logs -f 容器名` |
| 构建镜像 | `docker build -t 镜像名:版本 .` |
| 多容器启动 | `docker compose up -d` |
| 清理资源 | `docker container prune`/`docker image prune` |
