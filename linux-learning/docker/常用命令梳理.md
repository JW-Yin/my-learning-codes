
# Docker 常用命令大全
## 一、命令分类总览
1. **镜像管理**：拉取、查看、删除镜像；
2. **容器生命周期管理**：启动、查看、停止、删除容器；
3. **容器操作**：进入容器、复制文件、查看日志；
4. **核心参数**：端口映射、目录挂载、命名；
5. **其他常用**：清理资源、查看信息。

---

## 二、镜像管理命令
### 1. 拉取镜像（从 Docker Hub 下载）
**作用**：从 Docker 官方仓库（或私有仓库）下载镜像到本地。
**命令格式**：
```bash
docker pull 镜像名:版本号
```
**参数解释**：
- `镜像名`：比如 `nginx`、`mysql`；
- `版本号`：比如 `latest`（最新版）、`1.25`（指定版本），不写默认 `latest`。
**实操例子**：
```bash
# 拉取最新版 Nginx
docker pull nginx:latest

# 拉取指定版本 MySQL
docker pull mysql:8.0
```

---

### 2. 查看本地镜像
**作用**：查看本地已下载/构建的所有镜像。
**命令格式**：
```bash
docker images
# 或简写
docker image ls
```
**输出列含义**：
| 列名         | 含义                                  |
|--------------|---------------------------------------|
| REPOSITORY   | 镜像名称（如 nginx）                  |
| TAG          | 版本号（如 latest、v1）               |
| IMAGE ID     | 镜像唯一 ID（短 ID）                  |
| CREATED      | 镜像创建时间                          |
| SIZE         | 镜像大小                              |

---

### 3. 删除镜像
**作用**：删除本地不需要的镜像（必须先删除基于该镜像的所有容器）。
**命令格式**：
```bash
# 删除指定镜像（通过镜像名:版本 或 镜像ID）
docker rmi 镜像名:版本号
# 或
docker rmi 镜像ID

# 强制删除（即使有容器在用，谨慎用）
docker rmi -f 镜像名:版本号
```
**实操例子**：
```bash
# 删除 nginx:latest 镜像
docker rmi nginx:latest

# 强制删除（谨慎）
docker rmi -f a1b2c3d4e5f6
```

## 三、容器生命周期管理命令
### 1. 启动容器（最核心命令）
**作用**：基于镜像创建并启动一个容器。
**命令格式**：
```bash
docker run [参数] 镜像名:版本号
```
**高频参数（必记）**：
| 参数         | 作用                                  | 例子                                  |
|--------------|---------------------------------------|---------------------------------------|
| `-d`         | 后台运行容器（不霸占终端）            | `docker run -d nginx`                 |
| `-p 宿主机端口:容器端口` | 端口映射（宿主机端口 → 容器端口） | `docker run -p 8080:80 nginx`        |
| `-v 宿主机路径:容器路径` | 目录挂载（数据持久化）                | `docker run -v ~/html:/usr/share/nginx/html nginx` |
| `--name 容器名` | 给容器起个好记的名字                  | `docker run --name my-nginx nginx`    |
| `-it`        | 交互式终端（配合 /bin/bash 进入容器） | `docker run -it ubuntu /bin/bash`     |

**实操例子（组合用）**：
```bash
# 后台启动 Nginx 容器，映射 8080 端口，挂载本地目录，起名 my-nginx
docker run -d \
  -p 8080:80 \
  -v ~/nginx/html:/usr/share/nginx/html \
  --name my-nginx \
  nginx:latest
```

---

### 2. 查看容器
**作用**：查看运行中/所有容器的状态。
**命令格式**：
```bash
# 查看运行中的容器
docker ps

# 查看所有容器（包括已停止的）
docker ps -a
```
**输出列含义**：
| 列名         | 含义                                  |
|--------------|---------------------------------------|
| CONTAINER ID | 容器唯一 ID（短 ID）                  |
| IMAGE        | 基于哪个镜像启动的                    |
| COMMAND      | 容器启动时执行的命令                  |
| CREATED      | 容器创建时间                          |
| STATUS       | 容器状态（Up 运行中、Exited 已停止） |
| PORTS        | 端口映射信息                          |
| NAMES        | 容器名字                              |

---

### 3. 停止容器
**作用**：停止一个运行中的容器。
**命令格式**：
```bash
# 通过容器名或容器ID停止
docker stop 容器名/容器ID
```
**实操例子**：
```bash
# 停止 my-nginx 容器
docker stop my-nginx

# 通过容器ID停止
docker stop a1b2c3d4e5f6
```

---

### 4. 启动已停止的容器
**作用**：重新启动一个已停止的容器（不用重新 `docker run`）。
**命令格式**：
```bash
docker start 容器名/容器ID
```
**实操例子**：
```bash
# 启动已停止的 my-nginx 容器
docker start my-nginx
```

---

### 5. 重启容器
**作用**：重启一个运行中/已停止的容器。
**命令格式**：
```bash
docker restart 容器名/容器ID
```

---

### 6. 删除容器
**作用**：删除不需要的容器（必须先停止，或加 `-f` 强制删除）。
**命令格式**：
```bash
# 删除已停止的容器
docker rm 容器名/容器ID

# 强制删除运行中的容器（谨慎用）
docker rm -f 容器名/容器ID

# 批量删除所有已停止的容器（清理用）
docker container prune
```
**实操例子**：
```bash
# 先停止再删除
docker stop my-nginx && docker rm my-nginx

# 强制删除（谨慎）
docker rm -f my-nginx
```

## 四、容器操作命令
### 1. 进入运行中的容器
**作用**：进入容器内部，像操作虚拟机一样操作容器（比如查看文件、修改配置）。
**命令格式**：
```bash
docker exec -it 容器名/容器ID /bin/bash
```
**参数解释**：
- `-it`：交互式终端（必须加）；
- `/bin/bash`：进入容器后用 bash  shell（有些容器用 `/bin/sh`）。
**实操例子**：
```bash
# 进入 my-nginx 容器
docker exec -it my-nginx /bin/bash

# 退出容器（在容器内执行）
exit
```

---

### 2. 在宿主机和容器之间复制文件
**作用**：把宿主机的文件复制到容器，或把容器的文件复制到宿主机。
**命令格式**：
```bash
# 宿主机 → 容器
docker cp 宿主机文件路径 容器名:容器内路径

# 容器 → 宿主机
docker cp 容器名:容器内文件路径 宿主机路径
```
**实操例子**：
```bash
# 把宿主机的 index.html 复制到 my-nginx 容器的网页目录
docker cp ~/nginx/index.html my-nginx:/usr/share/nginx/html/

# 把容器的 Nginx 配置复制到宿主机
docker cp my-nginx:/etc/nginx/nginx.conf ~/nginx/conf/
```

---

### 3. 查看容器日志
**作用**：查看容器的运行日志（排查问题用）。
**命令格式**：
```bash
# 查看容器日志
docker logs 容器名/容器ID

# 实时查看日志（类似 tail -f）
docker logs -f 容器名/容器ID
```
**实操例子**：
```bash
# 查看 my-nginx 的日志
docker logs my-nginx

# 实时查看日志
docker logs -f my-nginx
```

---

## 五、核心参数专项（必记）
### 1. 端口映射（-p）
**作用**：让宿主机的端口转发到容器的端口（外部能访问容器内的服务）。
**格式**：`-p 宿主机IP:宿主机端口:容器端口`（宿主机IP可省略，默认 0.0.0.0）。
**例子**：
```bash
# 宿主机 8080 端口 → 容器 80 端口
docker run -d -p 8080:80 --name my-nginx nginx

# 宿主机 127.0.0.1:8080 → 容器 80（仅本机访问）
docker run -d -p 127.0.0.1:8080:80 --name my-nginx nginx
```

---

### 2. 目录挂载（-v，数据持久化）
**作用**：把宿主机的目录/文件挂载到容器，容器删了数据还在。
**格式**：`-v 宿主机路径:容器内路径`（宿主机路径必须是绝对路径，或用 `~` 表示家目录）。
**例子**：
```bash
# 挂载本地网页目录到 Nginx 容器
docker run -d \
  -p 8080:80 \
  -v ~/nginx/html:/usr/share/nginx/html \
  --name my-nginx \
  nginx
```

## 六、其他常用命令
### 1. 清理资源（释放空间）
```bash
# 清理所有已停止的容器
docker container prune

# 清理所有无标签镜像（<none>:<none>）
docker image prune

# 清理所有未使用的镜像、容器、网络、卷（谨慎用）
docker system prune
```

---

### 2. 查看 Docker 系统信息
```bash
# 查看 Docker 版本
docker --version

# 查看 Docker 详细信息（镜像数、容器数、存储驱动等）
docker info
```
