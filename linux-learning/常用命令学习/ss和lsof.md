## 一、先学 `ss`：查看网络端口/连接的“现代神器”
### 1. 先搞懂：`ss` 是干嘛的？
一句话：**`ss` 是用来查看 Linux 服务器上“网络连接”和“监听端口”的工具。**

- 什么是“监听端口”？
  比如你开了个网站（用80端口），服务器就得“守着”80端口，等着别人来访问——这就叫“监听”。
- 什么是“网络连接”？
  比如你用 SSH 连上了服务器，这就是一条“已建立的连接”。

### 2. 最基础：先看 `ss` 的“黄金组合命令”
新手直接记这个命令（**90% 的场景都用它**）：
```bash
sudo ss -tulnp
```
> 注意：前面加 `sudo` 是为了看到完整的进程信息，否则可能看不到“谁在用这个端口”。

#### （1）逐个拆解参数（别怕，很好记）
| 参数 | 大白话意思 | 为什么要用它？ |
|------|------------|----------------|
| `-t` | 只看 **TCP** 协议的 | 网站、SSH、数据库这些常用的都是 TCP |
| `-u` | 只看 **UDP** 协议的 | DNS、DHCP 这些用 UDP，平时用得少 |
| `-l` | 只看 **正在监听** 的端口 | 我们最关心“服务器开了哪些端口等着别人连” |
| `-n` | 用 **数字** 显示 IP 和端口 | 比如显示 `80` 而不是 `http`，速度更快，也更直观 |
| `-p` | 显示 **占用端口的进程名和 PID** | 知道“是谁在用这个端口”（比如是 nginx 还是 mysql） |

#### （2）执行命令，看输出（手把手解读）
执行 `sudo ss -tulnp` 后，你会看到类似这样的输出：
```
Netid  State    Recv-Q   Send-Q     Local Address:Port     Peer Address:Port   Process
tcp    LISTEN   0        128              0.0.0.0:22            0.0.0.0:*       users:(("sshd",pid=1234,fd=3))
tcp    LISTEN   0        128              127.0.0.1:3306          0.0.0.0:*       users:(("mysqld",pid=789,fd=30))
udp    LISTEN   0        0                0.0.0.0:68            0.0.0.0:*       users:(("dhclient",pid=567,fd=6))
```

**新手只需要重点看这几列**：
1.  `Local Address:Port`（本地地址:端口）：
    - `0.0.0.0:22`：表示 SSH（22端口）监听“所有网卡”——外网/内网都能连你的服务器 SSH。
    - `127.0.0.1:3306`：表示 MySQL（3306端口）只监听“本地”——只有服务器自己能连 MySQL，外网连不上（安全）。
2.  `Process`（进程）：
    - `("sshd",pid=1234)`：22端口被 `sshd`（SSH服务）占用，进程ID（PID）是 `1234`。
    - `("mysqld",pid=789)`：3306端口被 `mysqld`（MySQL）占用，PID是 `789`。

### 3. `ss` 最常用的“实战小技巧”
#### （1）只想看 TCP 监听端口（最常用）
```bash
sudo ss -tlnp
```
（去掉了 `-u`，就不看 UDP 了）

#### （2）查“某个特定端口”有没有被占用
比如查 8080 端口：
```bash
sudo ss -tulnp | grep 8080
```
- 如果有输出，说明 8080 被占用了；
- 如果没输出，说明 8080 是空的。

## 二、再学 `lsof`：查“端口被谁占用”的“终极武器”
### 1. 先搞懂：`lsof` 是干嘛的？
一句话：**`lsof` = List Open Files（列出打开的文件）**。

在 Linux 里，“一切皆文件”——网络端口、网络连接也是一种“文件”。所以 `lsof` 能用来查：
- 哪个进程占用了某个端口？
- 某个进程打开了哪些网络连接？

### 2. 最基础：`lsof` 查网络的“核心用法”
#### （1）先看所有网络相关的连接/端口
```bash
sudo lsof -i
```
> 同样加 `sudo`，否则可能看不到完整信息。

#### （2）执行命令，看输出（手把手解读）
执行后会看到类似这样的输出：
```
COMMAND  PID   USER   FD   TYPE DEVICE SIZE/OFF NODE NAME
sshd    1234   root    3u  IPv4  12345      0t0  TCP *:22 (LISTEN)
mysqld  789   mysql   30u  IPv4  78900      0t0  TCP localhost:3306 (LISTEN)
nginx   999   root    6u  IPv4  88888      0t0  TCP *:80 (LISTEN)
```

**新手只需要重点看这几列**：
1.  `COMMAND`：进程名（比如 `sshd`、`mysqld`、`nginx`）；
2.  `PID`：进程ID（杀进程的时候会用到）；
3.  `NAME`：端口/连接信息（核心！）：
    - `TCP *:22 (LISTEN)`：TCP 22端口正在监听所有网卡；
    - `TCP localhost:3306 (LISTEN)`：TCP 3306端口只监听本地。

### 3. `lsof` 最常用的“实战神技”（必学！）
#### （1）精准查“某个端口被谁占用”（99% 的人用 `lsof` 都是为了这个）
比如查 80 端口：
```bash
sudo lsof -i :80
```
（注意冒号 `:` 前面有个空格！）

输出会直接告诉你：
```
COMMAND  PID USER   FD   TYPE DEVICE SIZE/OFF NODE NAME
nginx   999 root    6u  IPv4  88888      0t0  TCP *:80 (LISTEN)
nginx  1000 www     7u  IPv4  88889      0t0  TCP *:80 (LISTEN)
```
→ 一目了然：80端口被 `nginx` 占用了，PID 是 999 和 1000。

#### （2）只查 TCP 协议的某个端口
比如查 MySQL 的 3306 端口（TCP）：
```bash
sudo lsof -i TCP:3306
```

## 三、最后总结：两个命令怎么选？
| 场景 | 用哪个命令？ | 示例 |
|------|--------------|------|
| 看服务器开了哪些监听端口 | `ss -tulnp` | `sudo ss -tulnp` |
| 查“某个特定端口被谁占用” | `lsof -i :端口` | `sudo lsof -i :80` |

### 新手必背的“两条命令”
1.  看所有监听端口：
    ```bash
    sudo ss -tulnp
    ```
2.  查80端口被谁占用：
    ```bash
    sudo lsof -i :80
    ```
