# find命令基础用法系统学习指南（含参数缩写+实战）

## 一、find命令基础认知
### 1. 命令全称与核心作用
- **find**：无官方缩写，英文直译就是「查找」，是Linux系统中用于在指定目录下递归查找文件/目录的核心工具。
- 核心特点：实时查找（遍历文件系统）、支持多条件组合、精准匹配，是日常定位文件的首选命令。

### 2. 基础语法格式
```bash
find [查找路径] [查找条件] [动作]
```
- **查找路径**：指定要查找的目录（必填，`.`代表当前目录，`/`代表根目录）；
- **查找条件**：按文件名、类型、时间等筛选（核心学习内容）；
- **动作**：找到文件后执行的操作（默认是「列出文件路径」，可选）。

## 二、核心用法1：按文件名查找（最常用）
### 1. 核心参数（含缩写释义）
| 参数 | 英文全称 | 作用 | 示例 |
|------|----------|------|------|
| `-name` | Name | 按**精确文件名**查找（区分大小写） | `find /tmp -name test.txt` |
| `-iname` | Ignore Name | 按文件名查找（忽略大小写） | `find /tmp -iname Test.txt` |

### 2. 实战示例（逐行解释）
#### （1）精确匹配文件名
```bash
# 在/tmp目录下查找名为test.txt的文件（区分大小写）
find /tmp -name test.txt
# 释义：查找路径=/tmp，条件=-name（Name）精确匹配test.txt，默认动作=列出路径
```
- 效果：仅返回`/tmp/test.txt`（如果存在），`/tmp/Test.txt`或`/tmp/test1.txt`都不会匹配。

#### （2）忽略大小写匹配
```bash
# 在当前目录（.）下查找名为test.txt的文件（忽略大小写）
find . -iname test.txt
# 释义：查找路径=当前目录，条件=-iname（Ignore Name）忽略大小写匹配test.txt
```
- 效果：会匹配`test.txt`、`Test.txt`、`TEST.TXT`等。

#### （3）通配符匹配（*任意字符，?单个字符）
```bash
# 在/var/log目录下查找所有.log后缀的文件（*匹配任意字符）
find /var/log -name "*.log"
# 释义：*通配符匹配.log前的任意字符，需用双引号包裹避免Shell解析

# 在/home目录下查找文件名以file开头、后接1个字符的txt文件（?匹配单个字符）
find /home -name "file?.txt"
# 释义：匹配file1.txt、filea.txt等，不匹配file12.txt
```

### 3. 避坑要点
- 通配符（`*`/`?`）必须用**双引号/单引号**包裹，否则Shell会先解析通配符，导致find命令接收不到通配符参数；
- `-name`区分大小写，日常查找优先用`-iname`避免漏查。

## 三、核心用法2：按文件类型查找
### 1. 核心参数（含缩写释义）
| 参数 | 英文全称 | 作用 | 常用类型值（英文/释义） |
|------|----------|------|-------------------------|
| `-type` | Type | 按文件类型查找 | `f`（File=普通文件）、`d`（Directory=目录）、`l`（Link=软链接） |

### 2. 实战示例（逐行解释）
#### （1）查找普通文件（排除目录/链接）
```bash
# 在/etc目录下查找名为passwd的**普通文件**（排除目录）
find /etc -name passwd -type f
# 释义：条件1=-name匹配passwd，条件2=-type f（File）限定为普通文件
```
- 效果：仅返回`/etc/passwd`（普通文件），如果有`/etc/passwd`目录则不会匹配。

#### （2）查找目录
```bash
# 在/opt目录下查找名为devsecops的目录
find /opt -name devsecops -type d
# 释义：条件=-type d（Directory）限定为目录，仅匹配目录类型的devsecops
```

#### （3）组合查找：所有.log后缀的目录（实战少，仅示例）
```bash
# 在当前目录下查找所有.log后缀的目录
find . -name "*.log" -type d
```

### 3. 常用文件类型速查表
| 类型值 | 英文 | 含义 | 适用场景 |
|--------|------|------|----------|
| f | File | 普通文件（文本/二进制/脚本等） | 查找配置文件、日志文件、脚本 |
| d | Directory | 目录 | 查找特定名称的目录 |
| l | Link | 软链接文件 | 排查链接失效问题 |
| c | Character | 字符设备文件 | 系统运维（如/dev/tty） |
| b | Block | 块设备文件 | 系统运维（如/dev/sda） |

## 四、核心用法3：按修改时间查找
### 1. 核心参数（含缩写释义）
Linux文件有3个核心时间属性，find命令常用**修改时间（mtime）**：
| 参数 | 英文全称 | 作用 | 格式说明 |
|------|----------|------|----------|
| `-mtime` | Modification Time | 按**文件内容修改时间**查找（单位：天） | `n`=正好n天前，`-n`=n天内，`+n`=超过n天 |
| `-mmin` | Modification Minute | 按修改时间查找（单位：分钟） | 格式同mtime，仅单位不同 |

### 2. 时间参数格式详解
| 格式 | 含义 | 示例 |
|------|------|------|
| `n` | 文件修改时间正好是n天前（精确到天） | `find / -mtime 7` → 7天前修改的文件 |
| `-n` | 文件修改时间在n天内（包含n天） | `find / -mtime -7` → 7天内（1-7天）修改的文件 |
| `+n` | 文件修改时间超过n天（不含n天） | `find / -mtime +7` → 8天及以上前修改的文件 |

### 3. 实战示例（逐行解释）
#### （1）查找7天内修改的.log文件
```bash
# 在/var/log目录下查找7天内修改的所有.log普通文件
find /var/log -name "*.log" -type f -mtime -7
# 释义：条件1=-name匹配.log，条件2=-type f限定普通文件，条件3=-mtime -7（7天内修改）
```
- 场景：DevSecOps日常排查近期更新的日志文件。

#### （2）查找超过30天未修改的大文件
```bash
# 在/data目录下查找超过30天未修改、大小超过100M的普通文件（结合-size，拓展）
find /data -type f -mtime +30 -size +100M
# 释义：-size +100M=大小超过100MB，用于清理过期大文件
```

#### （3）按分钟查找（应急响应常用）
```bash
# 查找当前目录下30分钟内修改的所有.sh脚本文件
find . -name "*.sh" -type f -mmin -30
# 释义：-mmin -30（30分钟内修改），应急响应时定位近期修改的脚本
```

### 4. 避坑要点
- `-mtime`的`n`是**24小时为1天**，比如`-mtime -1`代表「24小时内」，不是「1天内（自然日）」；
- 区分`-mtime`（内容修改）、`-atime`（访问时间）、`-ctime`（属性修改）：日常优先用`-mtime`，`-atime`受文件访问影响大（如cat文件会更新），参考价值低。

## 五、组合条件查找（实战高频）
### 1. 条件逻辑（含缩写释义）
| 参数 | 英文 | 作用 | 示例 |
|------|------|------|------|
| `-a` | And（默认） | 多个条件同时满足 | `find / -name *.txt -a -type f` |
| `-o` | Or | 满足任意一个条件 | `find / -name *.txt -o -name *.log` |
| `-not` | Not | 取反条件 | `find / -not -name *.txt` |

### 2. 实战示例
#### （1）多条件同时满足（默认-a，可省略）
```bash
# 查找/tmp目录下7天内修改、名为test.txt的普通文件
find /tmp -name test.txt -type f -mtime -7
# 释义：等价于 -name test.txt -a -type f -a -mtime -7，三个条件同时满足
```

#### （2）满足任意一个条件（-o）
```bash
# 查找/home目录下.txt或.log后缀的普通文件
find /home -type f \( -name "*.txt" -o -name "*.log" \)
# 释义：\( \)包裹分组条件，-o=Or，匹配.txt或.log文件（需转义括号避免Shell解析）
```

#### （3）条件取反（-not）
```bash
# 查找/opt目录下不是.sh后缀的普通文件
find /opt -type f -not -name "*.sh"
# 释义：-not=取反，匹配所有非.sh的普通文件
```

## 七、总结
### 核心知识点回顾（含缩写/关键参数）
1. **按文件名**：`-name`（精确/区分大小写）、`-iname`（忽略大小写），通配符`*`/`?`需用引号包裹；
2. **按文件类型**：`-type`（Type），常用`f`（普通文件）、`d`（目录）、`l`（软链接）；
3. **按修改时间**：`-mtime`（天）/`-mmin`（分钟），`-n`=n内、`+n`=超过n、`n`=正好n；
4. **组合条件**：默认`-a`（And）、`-o`（Or）、`-not`（取反），分组用`\( \)`。

### 记忆口诀
- find找文件，路径先指定；
- 文件名用name，iname不区分；
- 类型type加f/d，时间mtime分+-；
- 多条件用a/o，not取反要记牢。
