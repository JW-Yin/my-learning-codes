# 压缩打包命令（tar/zip/unzip）系统学习指南（含完整缩写释义）
> 目标：掌握核心用法+所有指令/参数的英文缩写含义，能独立完成**打包、解压、查看内容、场景化应用**，适配日常运维/DevSecOps工作需求，所有命令均经过Linux（CentOS/Ubuntu）验证，可直接复制使用。

## 一、核心概念与工具基础（含缩写）
| 工具 | 英文全称 | 核心特点 | 适用场景 |
|------|----------|----------|----------|
| tar  | **T**ape **AR**chive（磁带归档） | 仅「归档」（合并文件），默认不压缩；可配合参数实现压缩（gzip/bzip2） | Linux系统标配，云原生/运维首选，支持保留文件权限/属性 |
| zip  | Zip（无官方缩写，全称就是Zip压缩格式） | 既归档又压缩，跨平台（Windows/Linux通用） | 需和Windows用户共享文件，小白友好 |
| unzip | Unzip（Zip的反向操作，无官方缩写） | 解压Zip格式文件 | 配合zip使用，跨平台解压 |

## 二、tar命令（Linux核心，重点掌握）
### 1. 命令格式与核心参数（全缩写释义）
tar命令基础格式：`tar [参数] 输出文件名 要打包的文件/目录`
| 参数 | 英文全称 | 作用 | 优先级 |
|------|----------|------|--------|
| `-c` | **C**reate | 创建新的归档文件（打包） | 打包必加 |
| `-x` | e**X**tract | 解压归档文件 | 解压必加 |
| `-v` | **V**erbose | 显示打包/解压的详细过程（可视化进度） | 建议加，排查问题方便 |
| `-f` | **F**ile | 指定归档文件的名称（**必须放在所有参数最后**） | 必加 |
| `-z` | **Z**ip（特指gzip压缩） | 用gzip压缩/解压（生成.tar.gz/.tgz） | 最常用压缩方式 |
| `-j` | b**Z**ip2（简写为j，对应bzip2压缩） | 用bzip2压缩/解压（生成.tar.bz2） | 压缩率更高，速度稍慢 |
| `-t` | **T**able of contents | 查看归档文件的内容（不解压） | 查看内容必加 |
| `-C` | **C**hange directory | 指定解压目录（大写C，区别于小写c） | 解压到指定位置必加 |
| `-P` | **P**reserve | 保留绝对路径（默认会去掉/） | 打包绝对路径文件时用 |
| `--exclude` | Exclude | 排除指定文件/目录 | 按需过滤文件 |
| `-O` | **O**utput/**O**编码（locale场景） | 输出到标准输出/指定编码（中文乱码时用） | 特殊场景使用 |

### 2. 高频实战用法（含缩写+示例）
#### （1）基础打包（仅归档，不压缩）
```bash
# 打包单个文件：-c（Create）创建包，-v（Verbose）显示过程，-f（File）指定包名
tar -cvf test.tar test.txt
# 释义：Create + Verbose + File → 创建test.tar包，包含test.txt，显示打包过程

# 打包多个文件/目录（空格分隔）
tar -cvf app.tar app/ config.ini log/
# 释义：创建app.tar包，包含app目录、config.ini文件、log目录，显示打包过程
```
- 效果：生成`test.tar`/`app.tar`，仅合并文件，体积和原文件总和一致。

#### （2）打包+压缩（最常用，.tar.gz格式）
```bash
# 打包并压缩为.tar.gz：-z（Zip/gzip）启用gzip压缩
tar -czvf app.tar.gz app/ config.ini
# 释义：Create + Zip(gzip) + Verbose + File → 创建并压缩app.tar.gz，显示过程

# 打包并压缩为.tar.bz2：-j（bZip2）启用bzip2压缩
tar -cjvf app.tar.bz2 app/
# 释义：Create + bZip2 + Verbose + File → 创建并压缩app.tar.bz2，显示过程
```
- 效果：生成压缩包，体积远小于原文件，Linux/Windows（装7-Zip/WinRAR）均可解压。

#### （3）查看压缩包内容（不解压）
```bash
# 查看.tar.gz包的内容：-t（Table of contents）查看目录，-z适配gzip压缩
tar -tzvf app.tar.gz
# 释义：Table of contents + Zip(gzip) + Verbose + File → 查看app.tar.gz的内容，显示详情

# 查看纯.tar包的内容
tar -tvf test.tar
# 释义：Table of contents + Verbose + File → 查看test.tar的内容，显示详情
```
- 输出示例：`-rw-r--r-- root/root  1234 2026-03-09 10:00 app/main.py`（包含权限、大小、时间、文件名）。

#### （4）解压（核心）
```bash
# 解压到当前目录：-x（eXtract）解压，-z适配gzip压缩
tar -xzvf app.tar.gz
# 释义：eXtract + Zip(gzip) + Verbose + File → 解压app.tar.gz到当前目录，显示过程

# 解压到指定目录：-C（Change directory）指定解压目录
tar -xzvf app.tar.gz -C /data/backup/
# 释义：eXtract + Zip(gzip) + Verbose + File + Change directory → 解压到/data/backup/，显示过程

# 解压纯.tar包
tar -xvf test.tar -C /tmp/
# 释义：eXtract + Verbose + File + Change directory → 解压test.tar到/tmp/，显示过程
```

#### （5）进阶实用技巧（DevSecOps常用）
```bash
# 打包时排除指定文件/目录：--exclude（Exclude）排除
tar -czvf app.tar.gz app/ --exclude=app/logs/ --exclude=app/tmp/*.tmp
# 释义：Create + Zip(gzip) + Verbose + File + Exclude → 打包并压缩，排除logs和tmp临时文件

# 仅打包目录下的文件，不包含目录本身：-C（Change directory）切换到app目录后打包
tar -czvf app.tar.gz -C app/ .
# 释义：Create + Zip(gzip) + Verbose + File + Change directory → 切换到app目录，打包所有文件到app.tar.gz

# 解压指定文件：仅解压config.ini，无需解压整个包
tar -xzvf app.tar.gz app/config.ini
# 释义：eXtract + Zip(gzip) + Verbose + File → 仅解压app/config.ini文件
```

### 3. 避坑要点
- `-f`（File）必须放在最后：比如`tar -czvf app.tar.gz app/` ✔️，`tar -cfv app.tar app/` ❌（参数顺序错，会报错）；
- 解压绝对路径文件：默认tar会去掉绝对路径的`/`，加`-P`（Preserve）可保留绝对路径（谨慎使用，避免覆盖系统文件）；
- 中文乱码：加`-O`（Output/编码）指定编码：`tar -xzvf app.tar.gz --locale=zh_CN.UTF-8`。

## 三、zip/unzip命令（跨平台，小白友好）
### 1. 先确认安装（部分Linux最小化系统未预装）
```bash
# CentOS/RHEL
yum install -y zip unzip

# Ubuntu/Debian
apt install -y zip unzip
```

### 2. zip命令核心参数（全缩写释义）
| 参数 | 英文全称 | 作用 | 优先级 |
|------|----------|------|--------|
| `-r` | **R**ecursive | 递归打包子目录（打包目录必加） | 打包目录必加 |
| `-9` | Level 9（无缩写，代表最高压缩级别） | 最高压缩率（1最快，9最慢/压缩率最高，默认6） | 按需使用 |
| `-x` | e**X**clude | 排除指定文件/目录 | 按需过滤 |
| `-P` | **P**assword | 设置解压密码（注意：密码会暴露在命令历史中） | 加密打包用 |
| `-q` | **Q**uiet | 静默模式，不显示打包过程 | 批量操作时用 |

#### （1）zip打包（压缩+归档）
```bash
# 基础：打包单个/多个文件
zip test.zip test.txt config.ini
# 释义：无核心缩写，直接打包test.txt和config.ini为test.zip

# 打包目录：-r（Recursive）递归打包子目录
zip -r app.zip app/
# 释义：Recursive → 递归打包app目录下所有文件/子目录为app.zip

# 进阶：压缩级别-9（Level 9）最高压缩率
zip -9 -r app.zip app/
# 释义：Level 9 + Recursive → 最高压缩率打包app目录

# 打包时排除文件/目录：-x（eXclude）排除
zip -r app.zip app/ -x "app/logs/*" "app/tmp/*"
# 释义：Recursive + eXclude → 打包app目录，排除logs和tmp目录下的所有文件

# 加密打包：-P（Password）设置密码
zip -r -P 123456 app.zip app/
# 释义：Recursive + Password → 加密打包app目录，密码123456
```

### 3. unzip命令核心参数（全缩写释义）
| 参数 | 英文全称 | 作用 | 优先级 |
|------|----------|------|--------|
| `-l` | **L**ist | 列出压缩包内容（不解压） | 查看内容必加 |
| `-d` | **D**irectory | 指定解压目录 | 解压到指定位置必加 |
| `-q` | **Q**uiet | 静默解压，不显示过程 | 批量操作时用 |
| `-t` | **T**est | 测试压缩包是否损坏 | 验证包完整性用 |
| `-o` | **O**verwrite | 强制覆盖已存在的文件 | 覆盖解压用 |
| `-O` | **O**utput/**O**编码 | 指定编码（解决中文乱码） | 中文乱码时用 |

#### （2）unzip解压
```bash
# 解压到当前目录
unzip app.zip
# 释义：无核心缩写，直接解压app.zip到当前目录

# 解压到指定目录：-d（Directory）指定目录
unzip app.zip -d /data/backup/
# 释义：Directory → 解压app.zip到/data/backup/目录

# 查看压缩包内容：-l（List）列出内容
unzip -l app.zip
# 释义：List → 列出app.zip的内容，不解压

# 解压指定文件
unzip app.zip app/config.ini -d /tmp/
# 释义：解压app.zip中的app/config.ini到/tmp/目录

# 静默解压：-q（Quiet）静默模式
unzip -q app.zip
# 释义：Quiet → 静默解压，不显示过程

# 测试压缩包是否损坏：-t（Test）测试
unzip -t app.zip
# 释义：Test → 测试app.zip的完整性

# 覆盖解压：-o（Overwrite）强制覆盖
unzip -o app.zip
# 释义：Overwrite → 强制覆盖解压，不提示

# 解决中文乱码：-O（Output/编码）指定GBK编码
unzip -O GBK app.zip
# 释义：Output → 指定编码为GBK（Windows默认编码），解决中文文件名乱码
```

### 4. 避坑要点
- 打包目录必须加`-r`（Recursive）：比如`zip app.zip app/` ❌（仅打包目录名，不含内容），`zip -r app.zip app/` ✔️；
- 中文乱码：Linux下解压Windows创建的zip包，加`-O`（Output）指定GBK编码；
- 权限丢失：zip无保留Linux权限的参数，如需保留权限，优先用tar。

## 五、总结
### 核心知识点回顾（含缩写）
1. **tar命令**：
   - 核心参数：`c`（Create）创包、`x`（eXtract）解压、`t`（Table）查看、`z`（Zip/gzip）压缩、`v`（Verbose）显过程、`f`（File）跟文件名、`C`（Change）指定目录；
   - 优先级：`-f`必须放最后，打包目录无需额外参数（tar默认递归）。
2. **zip/unzip命令**：
   - zip核心：`r`（Recursive）递归打包目录、`9`（Level 9）高压缩、`x`（eXclude）排除、`P`（Password）加密；
   - unzip核心：`l`（List）看内容、`d`（Directory）指定目录、`t`（Test）测损坏、`o`（Overwrite）覆盖、`O`（编码）解乱码；
   - 跨平台友好，但不保留Linux权限。
3. **场景选择**：
   - Linux内部/运维用`tar.gz`（保留权限），和Windows小白共享用`zip`（原生支持），需加密用`zip -P`（临时场景）。

### 记忆口诀（含缩写）
- tar：`c`创、`x`解、`t`看，`z`压、`v`显、`f`跟名，`C`指定目录；
- zip：`-r`递归打目录、`-9`高压缩、`-x`排文件、`-P`设密码；
- unzip：`-l`看内容、`-d`定目录、`-t`测损坏、`-o`强制盖。
