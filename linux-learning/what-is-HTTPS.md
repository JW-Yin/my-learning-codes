HTTPS = HTTP + TLS 安全层，TLS 层工作在 HTTP 应用层与 TCP 传输层之间，为 HTTP 提供三大核心安全能力，保障端到端的传输安全：

- 机密性：采用混合加密机制，握手阶段通过非对称加密完成身份认证与对称会话密钥的安全协商，握手完成后用高性能的对称加密加密所有业务数据，杜绝明文窃听；
- 身份可信：服务端持有第三方权威 CA 机构签发的数字证书，客户端通过内置的 CA 根证书完成证书全链路校验，确认服务端是目标域名的合法持有者，防御中间人身份伪造；
- 完整性：通过 AEAD/HMAC 算法对传输数据做完整性校验，杜绝传输过程中的数据篡改与内容注入。

额外提醒：HTTPS 的安全边界是「端到端的传输链路安全」，它只能保障数据在传输过程中不被窃听、篡改、伪造，无法防御应用层漏洞（SQL 注入、XSS 等）、终端被入侵、DDoS 流量攻击等链路之外的安全风险。
