# 云原生安全/DevSecOps岗位 Linux 核心能力达标自检清单
> 适配场景：云原生安全/DevSecOps岗位入门&工作刚需，聚焦服务器主流发行版（CentOS/RHEL、Ubuntu、Debian），**完全贴合安全左移、容器/K8s底层、自动化运维、安全应急的岗位核心诉求**，剔除纯运维非刚需的冗余内容。
>
> 达标分级：
> - 「基础必达项」：入门门槛，100%必须掌握，不达标直接失去面试资格
> - 「进阶合格项」：岗位刚需，90%以上掌握可满足日常全场景工作，是初级与资深岗的核心分水岭

## 一、Linux 基础命令与日常操作（每日高频刚需）
### 基础必达项（100%掌握）
1.  熟练使用文件目录核心命令：`ls`、`cd`、`pwd`、`mkdir`、`rm`、`cp`、`mv`、`touch`、`ln`，掌握核心参数（如`ls -la`、`rm -rf`、`cp -a`、`ln -s`），明确软硬链接的本质区别与使用场景
2.  熟练使用文本查看与过滤核心命令：`cat`、`more`、`less`、`head`、`tail`、`grep`，掌握`grep`高频参数（`-r`递归、`-i`忽略大小写、`-v`反向过滤、`-n`显示行号、`-E`正则匹配）
3.  熟练使用管道符`|`、标准输入输出重定向（`>`、`>>`、`<`），能完成多命令组合的文本处理
4.  熟练使用压缩打包命令：`tar`、`zip`/`unzip`，掌握打包、解压、查看压缩包内容的核心用法
5.  熟练使用`find`命令基础用法，能按文件名、文件类型、修改时间查找文件

### 进阶合格项（岗位刚需）
1.  精通`sed`、`awk`核心用法，能完成文本替换、列提取、数据统计、关键字过滤等复杂文本处理
2.  熟练使用`xargs`命令，能结合管道完成批量文件操作
3.  掌握Linux通配符、正则表达式基础，能在`grep`/`sed`/`awk`中灵活使用
4.  掌握`which`、`whereis`、`type`命令，能快速定位命令路径与类型
5.  掌握`alias`别名配置、`history`历史命令管理，能优化日常操作效率

### 自检实操题（能独立完成即达标）
1.  找出`/var/log`目录下7天内修改过的`.log`后缀文件，打包压缩为`log_backup.tar.gz`并保存到`/backup`目录
2.  用awk提取Nginx访问日志中状态码为404的请求IP，去重并统计访问次数Top10
3.  批量替换`/data/config`目录下所有`.yaml`文件中的`192.168.1.100`为`10.0.0.100`，并备份原文件

## 二、用户与权限管理（安全岗核心重中之重）
### 基础必达项（100%掌握）
1.  熟练操作用户/用户组全生命周期管理：`useradd`、`userdel`、`usermod`、`groupadd`、`groupdel`、`gpasswd`，能完成用户创建、删除、权限变更、组归属调整
2.  精通Linux文件权限体系：rwx权限的数字/符号表示、`chmod`、`chown`、`chgrp`核心用法，**明确文件与目录的权限本质区别**（目录x为进入权限，文件x为执行权限）
3.  熟练使用`su`、`sudo`命令切换用户/执行特权命令，了解`sudo`的基础配置
4.  掌握`umask`的原理与配置，能修改默认文件/目录创建权限
5.  熟记`/etc/passwd`、`/etc/group`、`/etc/shadow`核心配置文件的结构与作用，能识别异常配置

### 进阶合格项（岗位刚需）
1.  精通SUID/SGID/Sticky Bit的原理、安全风险与排查方法，能识别高危SUID文件，防范提权风险
2.  精通`sudoers`文件的精准配置，能落地**最小权限原则**（限制用户仅能执行指定命令、禁止免密、禁止危险操作）
3.  掌握ACL访问控制列表（`getfacl`/`setfacl`），能实现精细化的文件权限管控
4.  掌握PAM认证机制基础，能配置密码复杂度、登录限制等安全策略
5.  熟练使用`last`、`lastb`、`lastlog`排查用户登录日志，能识别异常登录、暴力破解行为
6.  掌握用户登录安全配置，能禁用无用用户、锁定风险账号、限制root远程登录

### 自检实操题（能独立完成即达标）
1.  给普通用户`devops`配置sudo权限：仅允许执行`kubectl`、`docker`、`systemctl restart nginx`命令，禁止执行其他root权限操作，且每次执行sudo需要验证密码
2.  找出系统中所有带有SUID权限的文件，筛选出非系统默认的风险文件并给出处置方案
3.  配置系统密码策略：要求密码长度≥12位，必须包含大小写字母、数字、特殊字符，90天强制过期，禁止重复使用前5次的历史密码

## 三、进程与系统资源管理（容器底层核心基础）
### 基础必达项（100%掌握）
1.  熟练使用`ps`、`top`/`htop`查看进程信息，能识别进程PID、PPID、CPU/内存占用、运行状态、启动用户与命令
2.  熟练使用`kill`、`killall`、`pkill`终止进程，掌握不同信号量（`SIGTERM 15`、`SIGKILL 9`）的区别与使用场景
3.  熟练使用`free`查看内存使用、`df`/`du`查看磁盘占用、`uptime`查看系统负载，能快速定位资源瓶颈
4.  掌握`nice`/`renice`调整进程优先级，`nohup`/`&`管理后台进程
5.  掌握`systemctl`核心用法，能完成服务的启动、停止、重启、开机自启、状态查看

### 进阶合格项（岗位刚需）
1.  精通Linux进程状态（R/S/D/Z/T/X），能区分并处理僵尸进程、孤儿进程
2.  精通`/proc`伪文件系统，能通过`/proc/[pid]/`查看进程的启动参数、环境变量、打开的文件句柄、内存映射、网络连接等核心信息（容器底层、安全排查核心）
3.  掌握cgroups基础原理与核心用法，理解容器资源限制的底层实现
4.  熟练使用`lsof`、`pstree`、`vmstat`、`iostat`、`sar`，能完成系统性能监控、瓶颈排查、异常进程定位
5.  掌握systemd服务单元配置，能编写简单的自定义服务文件
6.  掌握恶意进程排查方法，能识别隐藏进程、异常外联进程、挖矿进程等风险程序

### 自检实操题（能独立完成即达标）
1.  找出当前系统占用CPU最高的5个进程，查看其启动命令、打开的文件句柄、监听的端口与关联的用户
2.  排查系统中的僵尸进程，定位其父进程并给出合规的处置方案
3.  通过`/proc`文件系统，查看docker daemon进程的环境变量、cgroups归属与打开的端口信息

## 四、网络配置与排查能力（云原生网络/安全防护基础）
### 基础必达项（100%掌握）
1.  熟练使用`ip`命令（替代ifconfig），能查看网卡配置、IP地址、路由表、ARP表，能临时配置IP、路由、开启/关闭网卡
2.  熟练使用`ping`、`traceroute`/`mtr`排查网络连通性与链路故障
3.  熟练使用`ss`/`netstat`查看端口监听状态、TCP/UDP网络连接，能快速定位端口占用进程
4.  熟练使用`telnet`/`nc`测试端口连通性，`host`/`nslookup`/`dig`排查域名解析故障
5.  掌握iptables基础规则配置，能实现端口放行、IP访问控制

### 进阶合格项（岗位刚需）
1.  精通TCP/IP基础原理，掌握三次握手、四次挥手流程，能识别TCP连接状态（LISTEN/SYN_SENT/ESTABLISHED/TIME_WAIT/CLOSE_WAIT）的含义与异常场景
2.  精通iptables/nftables四表五链，能配置精细化的防火墙规则、端口转发、NAT、访问控制策略，落地默认拒绝的安全原则
3.  熟练使用`tcpdump`抓包，能完成数据包过滤、保存、基础分析，能排查网络攻击、异常流量、通信故障
4.  掌握Linux网络命名空间netns的原理与操作，理解容器网络的底层实现
5.  掌握网桥、VLAN、策略路由基础配置，能适配云原生/容器网络场景
6.  掌握异常网络行为排查方法，能识别端口扫描、暴力破解、异常外联、DDoS攻击等安全事件

### 自检实操题（能独立完成即达标）
1.  用iptables配置规则：仅允许`10.0.0.0/24`网段访问本机22端口，其他所有IP访问22端口直接拒绝；放行本机80、443端口的对外访问
2.  用tcpdump抓取本机8080端口的TCP数据包，过滤出三次握手与四次挥手的包，保存为`traffic.pcap`文件
3.  排查本机所有对外的ESTABLISHED状态网络连接，筛选出非内网IP的外联连接，定位对应的进程与启动用户，识别异常外联行为

2.  掌握rsyslog基础配置，能实现日志本地分流、远程集中转发

5.  掌握Linux入侵排查全流程，能结合日志完成恶意程序、提权操作、横向移动等安全事件的溯源分析
