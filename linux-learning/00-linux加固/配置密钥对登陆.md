### 一、核心原理（先简单理解一下）
1.  你在**本地Ubuntu电脑**上生成一对“钥匙”：
    - **私钥**（`id_rsa`）：相当于你家门的钥匙，**绝对保密，只能存在你自己的电脑上，不要给任何人**。
    - **公钥**（`id_rsa.pub`）：相当于做好的锁头，你可以把它放到云服务器上。
2.  配置好后，你登录服务器时，本地会用私钥去“开锁”，服务器验证公钥匹配，就直接让你登录，全程不需要输密码。

---

### 二、详细操作步骤

#### 第一步：在本地Ubuntu生成密钥对
在你的**本地Ubuntu终端**执行：
```bash
ssh-keygen
```
执行后会有一系列提示，**全程直接按回车即可**（不用设置密码，除非你想给私钥再加一层密码保护）。

执行完后，你会看到类似这样的输出，说明密钥对生成成功：
```
Your identification has been saved in /home/你的用户名/.ssh/id_rsa
Your public key has been saved in /home/你的用户名/.ssh/id_rsa.pub
```

---

#### 第二步：把公钥“安装”到云服务器上
这是最关键的一步，用一条命令就能自动完成，无需手动复制粘贴：
```bash
ssh-copy-id 你的云服务器用户名@服务器公网IP
# 示例：ssh-copy-id jw-yin@123.57.139.216
```

执行后，会提示你输入一次云服务器的登录密码（这是最后一次输密码），输完回车，看到以下提示就说明成功了：
```
Number of key(s) added: 1
Now try logging into the machine, with:   "ssh 'jw-yin@123.57.139.216'"
and check to make sure that only the key(s) you wanted were added.
```

---

#### 第三步：测试免密登录
现在直接用SSH登录，试试是不是不用输密码了：
```bash
ssh jw-yin@123.57.139.216
```
如果直接就登录进去了，说明免密配置成功！

---

### 三、【强烈推荐】安全加固：禁用服务器的密码登录
既然已经有了更安全的密钥登录，建议彻底禁用密码登录，杜绝黑客暴力破解密码的风险。

1.  登录到云服务器，编辑SSH服务配置文件：
    ```bash
    sudo vim /etc/ssh/sshd_config
    ```
2.  找到以下两个配置项，修改为 `no`（如果被注释了，就取消注释并修改）：
    ```ssh
    PasswordAuthentication no
    PermitRootLogin no
    ```
3.  保存退出，重启SSH服务让配置生效：
    ```bash
    sudo systemctl restart sshd
    ```

现在你的服务器只能用密钥登录，既方便又安全！

---

### 四、补充说明
1.  **私钥备份**：你的私钥文件在 `~/.ssh/id_rsa`，建议备份到安全的地方（比如加密的U盘），如果换电脑了，把私钥复制过去就能继续用。
2.  **多台电脑登录**：如果你想从多台本地电脑免密登录这台服务器，只需要在每台电脑上生成密钥对，然后把每台电脑的公钥都用 `ssh-copy-id` 传到服务器上即可。
3.  **如果免密失败**：检查服务器上的权限，确保以下目录和文件的权限正确（在服务器上执行）：
    ```bash
    chmod 700 ~/.ssh
    chmod 600 ~/.ssh/authorized_keys
    ```


**可以，而且这是云服务器 SSH 最标准、最推荐的安全方案**：
**22 端口对 0.0.0.0/0 开放 + 只允许密钥登录、完全关闭密码登录 = 非常安全**。

---

## 为什么这样配置足够安全？
1. **密码登录是 99% 入侵风险的来源**
   全网一直有机器人在扫 22 端口，尝试弱密码爆破。
   只要**关掉密码登录**，它们再怎么扫都没用。

2. **SSH 密钥是非对称加密**
   - 公钥放在服务器
   - 私钥只存在你本地电脑
   没有你那把私钥，就算知道用户名、IP、端口，也完全登不进去。

3. **业界主流云服务器全都这么用**
   阿里云、腾讯云、AWS、Azure 官方安全最佳实践里，
   **推荐配置就是：开放 22 → 禁用密码 → 只留密钥登录**。

---

## 你现在只需要做这 3 步（Ubuntu）
### 1. 先确认你已经能用密钥正常登录
确保你现在可以这样连上（不用输密码）：
```bash
ssh jw-yin@123.57.139.216
```

### 2. 编辑 SSH 配置，关闭密码登录
```bash
sudo nano /etc/ssh/sshd_config
```

找到或修改这几项：
```ini
# 禁用密码登录
PasswordAuthentication no

# 允许密钥登录（默认就是 yes，确认一下）
PubkeyAuthentication yes

# 如果你不用 root 登录，可以这样加固
PermitRootLogin prohibit-password
```

### 3. 重启 sshd 生效
```bash
sudo systemctl restart sshd
```

**做完这一步，你的服务器就彻底不怕暴力破解了。**

---

## 再给你 2 个超简单的加固小建议
1. **私钥自己保管好**
   不要发给别人、不要上传到网盘、不要写在代码里。

2. 本地私钥权限设为 600（Ubuntu 已经默认这样）
   ```bash
   chmod 600 ~/.ssh/id_rsa
   ```

---

## 结论（直接照这个做就行）
**22 端口 0.0.0.0/0 + 仅密钥登录 = 安全、省心、不怕家里公网IP再变。**
比你之前“只放行单个固定公网IP”更稳定，安全等级反而更高。
