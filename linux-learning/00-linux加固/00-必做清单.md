# 阿里云ECS初始化配置手册

## 一、重置系统至初始状态
> ⚠️ 操作前必读：重新初始化系统盘会**彻底清除系统盘所有数据**，请先创建快照备份！

1.  停止ECS实例
2.  进入实例详情页 -> 切换到 **存储与备份** 标签页
3.  找到系统盘，点击右侧 **重新初始化磁盘**
4.  选择初始镜像（如 Ubuntu 22.04），设置登录密码，确认执行

---

## 二、系统初始化后必做操作

### 2.1 配置本地SSH保活（防止连接超时断开）
在你的**本地Ubuntu电脑**终端执行：

1.  编辑SSH配置文件：
    ```bash
    vim ~/.ssh/config
    ```
2.  添加以下内容并保存退出：
    ```ssh
    Host *
        ServerAliveInterval 60
        ServerAliveCountMax 3
    ```
    *注：每60秒发送一次心跳包，连续3次无响应才断开*

---

### 2.2 配置网络安全组（防火墙）
进入阿里云ECS控制台 -> 实例详情页 -> **网络与安全组** -> 入方向规则。

**仅保留以下3条核心规则，删除其他冗余规则：**

| 规则用途 | 协议类型 | 端口范围 | 访问来源 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| **SSH远程管理** | SSH(22) | 22 | **你的本地公网IP** | 仅允许自己的设备连接，禁止开放给 `0.0.0.0/0` |
| **HTTP网站访问** | HTTP(80) | 80 | `0.0.0.0/0` | 搭建网站必配，允许全网访问 |
| **HTTPS加密访问** | HTTPS(443) | 443 | `0.0.0.0/0` | 加密网站必配，允许全网访问 |

---

### 2.3 创建日常操作用户（禁止长期用root）
通过SSH登录云服务器（默认用户 `ubuntu`），依次执行：

1.  创建新用户（将 `yourusername` 替换为你自定义的用户名）：
    ```bash
    sudo adduser yourusername
    ```
    *按提示设置密码，其余用户信息一路回车即可*

2.  给用户添加sudo管理员权限：
    ```bash
    sudo usermod -aG sudo yourusername
    ```

3.  **验证**：新开一个终端窗口，用新账号登录，执行 `sudo su` 能切换到root即配置成功。

---

### 2.4 更新系统基础环境
```bash
# 1. 更新软件源列表
sudo apt update

# 2. 升级所有已安装软件（修复安全漏洞）
sudo apt upgrade -y

# 3. 安装常用基础工具
sudo apt install -y wget curl net-tools unzip vim

```
